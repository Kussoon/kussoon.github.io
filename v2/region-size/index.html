データの出典・表示について
  • 輪郭：Natural Earth（1:50m、Admin 0 / Admin 1、パブリックドメイン）。実効支配境界をベースとする概略図で、領土に関する立場を示すものではありません。
  • 日本の面積：国土地理院「全国都道府県市区町村別面積調」（2026年7月1日）。
  • 米国・各州：米国国勢調査局・州別面積（2010年、総面積）。沿岸水域等を含みます。
  • その他の国・地域：国連統計部 UNdata（国・地域別 Surface area）。追加のアジア46件は国連人口統計年鑑2025・表3（Surface area）。台湾は台湾内政部統計。

地域ごとに正積方位図法で投影した輪郭を、公表面積に応じて等方的に補正しています。輪郭の簡略化、小島の省略（特にモルディブなどの島国）、面積の集計基準の差により、実際の距離や境界と完全には一致しません。面積比を知るための学習用試作です。

# 全国マップそのまま・都道府県だけにフォーカスする試作

URL: https://kussoon.com/v2/national/study-pref-trial/index.html?studyPref=28

- 正式全国版 `maps/national-municipalities.html` をコピーした**試作ページ**。国土全体の2026年データ、既存の地図描画、全国1,905区域のラベル生成・密度制御・ズーム・クリック操作・吹き出しを変更しない。
- 通常の全国版 `?pref=28` のように県単位の20m地図モードへ切り替えない。最初から全国表示モードのまま兵庫県の県境の全体に25%の余白をとり、近隣県の形状を残す。
- 非対象県の地名は**全国ラベルの配置計算が済んだ後で CSS非表示**とする（2文字県コードの前方一致）。座標・優先順位・フォント・衝突回避のアルゴリズムは一切変更しない。県内で一部の地名が密度制御により非表示になることは正式版と同じであり、この試作では意図的に補正しない。
- 試作ページには `studyPref=28`（兵庫）、`studyPref=27`（大阪）等の47県の県コードを指定できる。パラメータ未指定は兵庫県で開始する。
- 正式地図、全共有JS、行政区域データ、規則集、従来の県別学習・クイズは改変しない。実機で県境の残り方・ラベルの読みやすさ・検索等を確認し、本番採用するまでは全国本番に導入しない。
- 注意: 試作のHTML本体は正式版の2026-11-07時点の一時的コピーであるため、採用する場合は**本番全国版HTMLへ表示範囲指定とCSSマスク部分だけ**移植し、二重管理を残さない。

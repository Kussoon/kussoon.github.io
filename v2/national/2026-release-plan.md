# 全国市区町村マップ 2026 — 正式版移行台帳（RC1）

対象：`v2/national/2026-release-candidate.html`。基準は [全国 V2 仕様台帳](../audit/v2-national-current-spec-20261104.md) と [メンテナンス規約](MAINTENANCE_RULES.md)。正式採用を宣言する記録ではなく、変更・検証と課題を明示するための台帳。

## 正式版に入れる仕様
1. 全国47都道府県・計1,905市区町村等の区域（2026年行政区域）。都道府県コードで隣県の所属を判別できる淡い色を塗り、市区町村は属する県の色を維持する。
2. 選択区域はオレンジ塗替えを廃止し、元の県色のまま市区町村の面全体を約1.8秒で明滅。選択解除・次の選択時は旧選択の明滅を停止。動きを減らす設定では静的強調。
3. 全国全域でzoom/panとともにラベルを段階表示。初期読み仮名OFF。郡・町村名の2段表示を維持し、ON時は読みを各名称に付ける。検索、役所・役場住所、公式サイト・Wikipedia・経路へのリンク、戻る操作を維持。
4. Workerとmainフォールバックを保護し、県別に遅延読み込み、現行キャッシュ予算を守る。地形の境界座標を個別手動補正しない。クイズの未公開状態は変えない。
5. `progressive-color-test.html` と`progressive-shared-test.html`、従来pilotには触れない。RC1を正式版の既存パスに無断上書きしない。

## 検証済みと未検証を分ける
- **自動検査で検証済み**：既存の全国回帰契約、7県共通TopoJSON＋40県旧版フォールバック、Android相当Chromium・iPhone相当WebKitでの04宮城、07福島、28兵庫の色分け・選択元色・明滅・解除、読み仮名初期OFF。
- **RC1で再検査する**：全国47県の検索/ロード回帰、郡表示・地名、選択状態・パン・ズーム・吹き出し、色の復帰、PC/Android/iPhoneのレイアウト。差分と測定を自動保存。
- **既知の保留**：地図の端で境界が局所的に太く見える現象（利用者の判断で現状許容）。概要図と詳細図の境界不一致、7県以外の詳細共通Topology未切替、量子化/簡略化Topologyの縮退疑い2,577件、細い島と飛地の形状、47県隣接ペアの配色識別性、実機の滑らかさ、動きを減らす設定時の静的強調。
- **判定区分**：A=範囲を明記し試験で確認 / B=未反映 / C=理由付き意図的保留 / 要確認=事実未確定。過去PRの成果は削除せずS番号で対応付ける。

## 完了判定
新しいPRは必ず自動検査を通し、利用者のiPhone/Android実機評価を受ける。試験ページを作っただけで正式版完成とはみなさない。国の行政区域データの更新や縮退問題は監査課題として別管理する。

# Kussoon 地域学習システム V2

開始日：2026-10-30  
状態：芦屋市の自動配置と西宮市の特殊形状・隣接町名でV2比較試験中

## 目的

現在の西宮市・宝塚市・尼崎市・伊丹市・芦屋市の町名検索／学習、および兵庫県市町村学習を、公開版を維持したまま汎用的な地理学習エンジンへ発展させる。将来は全国の都道府県、市区町村、町・丁目、世界の国名へ対応する。

**最優先：大量の地名ラベルの手動位置調整をできる限りなくす。**

## 原則

- 既存公開URLは原則維持。既存HTMLを直接置き換えない。
- V2の試験コード、スタイル、データ、画面は基本的に `/v2/` 以下に隔離する。
- 地理データ、属性データ、ラベル候補・例外補正、共通プログラム、画面UI、地域設定を分離する。
- 行政上の親子関係と、「阪神間」「関西」「西宮市26コミュニティ」「兵庫県10地域」などのグループを混同しない。
- SVG / Leaflet / D3 等の方式を決め打ちせず、実測の後に採用する。
- 地図操作は現行のB案（地図をクリックするとホイール操作を地図に切替、外をクリックするとページスクロールに戻す）や直接クリック・タップ選択、ピンチ・ドラッグとの両立を維持する。
- 既存の独自境界、飛地、面のない町名、丁目の統合、郵便番号検索、クイズと復習を失わない。
- 出典、ライセンス、加工記録は元リポジトリの台帳を確認し、転記／変更の際には改変履歴を残す。
- 新規HTMLにはUmamiとサイト共通7リンクを設置し、試験ページには `noindex` を設定する。試験ページをサイトマップに掲載しない。
- `/v2/` はインターネット公開領域であり、機密情報を保管しない。

## 管理対象と担当

公開サイト本体は [Kussoon/kussoon.github.io](https://github.com/Kussoon/kussoon.github.io)。現行の6地域は各別リポジトリで運用する。

- Chat：要件・設計・差分レビュー
- Codex：設計に沿った試作コード・自動テスト・未マージPR
- Work：必要なブラウザ比較・公開確認・合意後のマージ
- ユーザー：iPhone等の実機確認
- Deep Research：追加の地理データと利用条件調査が必要な場合のみ

`main` から作業ブランチを切り、PRで確認してからマージする。既存公開ページの改変、フォルダ・リポジトリの移動、削除、改名は別の承認を要する。試験の成果を正式ページへ反映する際も地域単位で比較・検証する。

## 第1弾の完了条件

- このREADME、ロードマップ、現行台帳、設計案、試験トップが `/v2/` に存在する。
- 試験トップから存在しないV2ページへ誘導しない。
- 共通7リンクとUmamiを備え、試験トップには `noindex` がある。
- 差分が `/v2/` 内だけで、既存ページに変更がない。
- この段階ではラベル自動配置やクイズの実装・性能は未検証であると明記する。

## 今後の進め方

最初の技術検証は芦屋市59町名。自動配置位置、区域外へのはみ出し、ラベル衝突、手動補正件数を数値比較する。次に兵庫県49区域で「町名以外でも同じエンジンが使えるか」を検証する。正式ページの置換は最後に個別判断する。

## 第2弾：芦屋市ラベル比較（試験中）

59の町名と60の地図面を、既存の手動座標と紐づけて抽出した。 `/v2/ashiya/labels.html` で重心・Polylabel・簡易衝突回避の結果を比較できる。計測値はプロトタイプの概算であり、現時点で正確性や表示品質を保証しない。

ローカルで自動テストを走らせる場合：

```sh
node --test v2/tests/label-engine.test.cjs
```

正式な表示確認後、ラベルの表示密度・拡大縮小時の可読性を次工程で改善する。既存の `/ashiya/` は変更していない。

## 芦屋市：読み仮名と1行の上下微調整（追加試作）

既存の芦屋市町名検索から全59件の読みを再利用し、漢字のみ／漢字＋小さな読み／ひらがなのみを切り替える独立した試験画面を作成。ラベルは原則1行で、重なりが出る場合だけ上下に半文字～1.5文字移動する候補を比較する。既存の2行表示実験のコードは変更せず、PRは別に管理する。

```sh
node --test v2/tests/readable-labels.test.cjs
```

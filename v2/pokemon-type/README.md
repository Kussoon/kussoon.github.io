# 18タイプ相性トレーニング v1.0

公開入口: https://kussoon.com/v2/pokemon-type/

## 完成版のページと仕様

| ページ | モード | 仕様 |
| --- | --- | --- |
| index.html | 初級「まなぶ」 | 18タイプの単タイプ攻撃・防御一覧 |
| index.html | 初級「れんしゅう」 | 技1タイプ × 防御1タイプの選択 |
| index.html | 初級「クイズ」 | 4択・10問・初級専用の間違い復習記録 |
| advanced.html | 上級「まなぶ」 | 防御側2タイプ選択、18技・6種の倍率と計算過程 |
| advanced-practice.html | 上級「れんしゅう」 | 技1タイプ × 防御2タイプ、計算内訳とランダム変更 |
| advanced-quiz.html | 上級「クイズ」 | 6択・10問・重複なし・上級専用の間違い復習記録 |

- 「上級」の3ページは**独立したHTMLページ**で、初級からの移動は通常のリンク。以前のJavaScript切替ボタンが無反応だったため、この方法を変更しない。
- 初級と上級の復習データはブラウザの `localStorage` に分離保存する。
- 読めない漢字にはふりがなを付ける。動的表示には、ふりがな付き文字列またはひらがなを使う。
- 公式の画像・ロゴ・キャラクター素材は使わず、独自のSVGタイプアイコンを使用。
- 本編の一般的な18タイプ相性のみ扱い、特性・持ち物・特殊な技の例外は扱わない。
- ×0、×0.25、×0.5、×1、×2、×4の6通り。攻撃タイプは1つ、防御側は上級のみ異なる2タイプ。
- iPhone SE等の小画面でクイズ中の見出しを隠して回答欄・次へボタンを表示する仕様を維持する。
- 公式サイトの内容ではない、非公式学習ツール。

## 回帰検査

```sh
node --test v2/pokemon-type/tests/regression.test.mjs
```

- チェック対象: 4ページのJavaScript構文、公開メタ情報、学習画面間のリンク、18タイプルールの同一性、単タイプ324通り、複合タイプ2,754通り、上級クイズの6択・10問・復習機能。
- GitHub Actions: `.github/workflows/pokemon-type-regression.yml`。関連ファイルのpush/PRで実行。
- 数値検査だけではブラウザ操作を証明できない。改修時はスマートフォンの実機で「まなぶ」「れんしゅう」「クイズ」を初級・上級とも確認する。

### 実機スモークテスト

1. トップから「学ぶ・遊ぶ」→「18タイプ相性トレーニング」が開く。
2. 初級「まなぶ」で攻撃・防御の切替と、18タイプの選択。
3. 初級「れんしゅう」で技・相手の変更と結果更新。
4. 初級「クイズ」で10問回答、次へ、結果、復習と中断。
5. 上級「まなぶ」リンクで独立ページへ移動、2タイプ選択で相性一覧更新。
6. 上級「れんしゅう」リンクで独立ページへ移動、攻撃1・防御2、ランダム組み合わせ。
7. 上級「クイズ」リンクで独立ページへ移動、6択・10問・結果・復習。
8. 初級・上級の相互移動、iPhoneの下部ブラウザバーと「つぎの問題へ」の干渉がないこと。

## 変更時のルール

既存の完成機能を先に確認してから追加する。相性データを編集する場合は必ず全324通り・2,754通りの回帰テストを通す。独立ページへの通常リンクを、単純なJavaScriptタブへ戻さない。サイト内ほかのV2地図システムは編集対象外。

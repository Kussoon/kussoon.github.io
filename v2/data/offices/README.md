## 2026-11-01：吹き出しの利用目的を整理

庁舎名・郵便番号・住所は地域を知るための代表的な所在地として表示するだけであり、庁舎を訪問させることは目的としない。B案の吹き出しを維持し、施設ごとの「庁舎案内」「ここへ行く」ボタンを削除した。選択した**市区町村・行政区**の「公式サイト」「Wikipedia」の2リンクのみ表示する。神戸市中央区の場合、中央区役所と神戸市役所の両所在地は表示したまま、リンクは中央区の情報を開く。多可町の公式トップページURLも確認して登録。

## 2026-11-01：代表地点までの交通経路を調べる

地域学習の吹き出しは「公式サイト」「Wikipedia」「ここへ行く」の3ボタンを横並びで表示する。最後のリンクは役所への訪問案内ではなく、**その地域の代表地点までの移動距離・所要時間・交通手段・ルートをGoogleマップで知る**ためのもの。Googleマップの経路案内を開き、出発地と移動方法は利用者が選ぶ。市町村は本庁舎、政令指定都市の区は区役所を目的地にする。区の吹き出しは区役所と市役所両方の住所を引き続き表示。未確認の住所を目的地にせず、ボタンを無効表示する。「庁舎案内」は復活させない。

# 全国共通庁舎データ：兵庫県

`28.json` は仕様書 `../../national/OFFICES-DATA-SPEC.md` の schemaVersion 2。
確認日（UTC）は2026-10-31。2021年の行政区域形状とは独立して更新する。

- 対象：41市町＋神戸市9区、50地域・50施設。
- 確認済み：49施設。住所・庁舎固有郵便番号は自治体公式本文を照合。
- 再確認待ち：多可町（28365）1施設。公式トップ・庁舎案内が503/TLSエラー。
  検索結果には所在地があるが本文を再確認できないため、住所・郵便番号・案内URLはnull。
  成功件数に含めず、経路案内を有効化しない。
- Wikipedia：50地域の記事の存在・記事名をweb readerで確認。中央区・北区・西区は神戸市、太子町は兵庫県の限定記事。

`28-sources.json` に公式ページのHTTP確認結果、郵便番号周辺の短い照合記録、Wikipediaの確認方法を保持する。
公的照合用一覧：<https://www.j-lis.go.jp/spd/code-address/kinki/cms_14914183.html>。
6桁団体コードの末尾検査数字を除いた5桁を、既存の行政区域JSON・読み仮名辞書に照合した。

神戸市北区役所の郵便番号はJ-LIS一覧では651-1114だが、自治体公式本文の庁舎固有郵便番号651-1195を優先。
北神区役所や各市町の支所は今回の対象外。市役所・本庁舎と教育委員会など別施設を取り違えない。
西宮市公式案内はHTTPSの現行ドメイン `www.nishi.or.jp` を使用する。
旧パイロットJSONは既存の参照を壊さないため保持し、公開吹き出しは新JSONから読む。

`regions` に施設の住所を複製せず、`officeIds` で `offices` を参照する。
区は区役所を先頭、市役所を次に指定する。神戸市役所の施設情報は一箇所のみ。
区役所が未確認でも、市役所が確認済みなら市役所への経路案内は利用できる。
県別JSONは表示範囲に兵庫県が含まれるときだけ取得し、失敗時も地図表示を継続する。

## 検証

```sh
node v2/tests/office-directory.test.cjs
# PlaywrightとChromiumがある環境で、リポジトリを静的配信して実行
python -m http.server 8000
BASE_URL=http://127.0.0.1:8000 node v2/tests/office-popup.browser.cjs
```

ブラウザテスト：375/768/1280px、初期6地域、区・市の別経路、×後の選択保持、再選択、
右下操作ボタンとの非重複、未確認区役所、庁舎JSON取得失敗、対象県以外の遅延読込。
CDNに接続できない検証環境では `TOPOJSON_PATH` に既存CDNスクリプトのローカルコピーを指定できる。

既存テストは変更前のmainでも12件失敗：centered-labels 2件（診断線の旧記述）、density 5件、readings 5件。
地図・ラベル計算や読み仮名の変更を避けるため、今回のPRでは修正しない。

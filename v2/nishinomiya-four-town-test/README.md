# 西宮市4町のラベル位置比較（V2試験）

## 対象
- すみれ台：3丁目を統合
- 宝生ケ丘：2丁目を統合（実データの文字形を保持）
- 仁川町：6丁目を統合
- 一ケ谷町：町域1件（実データは「ケ」表記）

## データ
正式公開の `/nishinomiya/data/nishinomiya-towns.topojson` を読み取ってブラウザ側でTopoJSONの形状を結合します。元データは編集せず、別の境界線を作りません。

## 3つのラベル候補
1. Polylabel相当：区域内にある候補点のうち境界から遠い位置（75×75候補の近似。正確なPolylabel実装の結果と一致することは保証しない）
2. 南北中央の水平線が区域と交わる区間の左右中央
3. 南北中央から上下30%の61本の水平断面で候補を選び、上下の中心からの距離、断面の幅、境界との距離を重み付け

いずれも初期の候補位置を一回算出し、ズームのたびに移動する方式ではありません。丁目は別々でなく町名に統合した形で検証します。

## 比較範囲と未確認事項
外部地図の地名座標は取得していません。地理院地図・マピオン・Yahoo!マップの公式ラベル位置と一致することを主張しません。実機の位置・文字の自然さを確認してから、全国V2の共通規則に取り込むか判断します。

対象URL：`/v2/nishinomiya-four-town-test/`。noindex。正式版と通常全国V2は変更しません。

# 京都府V2（2026年版・36区域）

大阪府で実機確認済みのV2共通クイズを、京都府でも同一の共通エンジン・画面・CSSで使用する検証版。

## 地域区分

京都府の公式統計 [地域で見る](https://www.pref.kyoto.jp/tokei/analysis/chiiki/index.html) に基づく8地域。

- 丹後：4区域
- 中丹：3区域
- 南丹：3区域
- 京都市域：11区
- 乙訓：3区域
- 山城北部：6区域
- 学研：3区域
- 相楽東部：3区域

合計36区域、重複なし、欠落なし。府の基本5地域のうち山城地域のみ4地域に分ける。京都市は政令指定都市の11区を出題単位とする。

## 共通機能と保護事項

- クイズ1：名前から場所をタップ、クイズ2：点滅区域の名前を4択で回答
- 4択は地図の**下**、開始・終了時も地図上端を動かさない
- 直接隣接する自治体を優先、少数地域は地域全区域を選択肢に含む
- 初回正解だけ得点、誤答した問題だけ復習、途中終了、2〜3個の等幅結果ボタン
- 地域全体／府の全体の4つの操作ボタン、読み仮名・郡名
- 共有コード：`/v2/municipalities/shared/regional-quiz.js`、`quiz-app.js`、`quiz.css`
- 既存の兵庫県版、大阪府版、全国正式地図には変更を加えない

# 山口県V2 地域学習・クイズ1/2

2026年11月9日。全国V2地域区分方針（`v2/national/PREFECTURE_STUDY_REGION_POLICY.md`）に基づく。

地域区分は[気象庁：特別警報・警報等の発表区域](https://www.jma.go.jp/jma/kishou/know/yougo_hp/shichoson_ichiran.html)に掲載された山口県の一次細分区域（東部・中部・北部・西部）を採用。県の[行政上の8圏域](https://faq.pref.yamaguchi.lg.jp/faq/detail.aspx?id=1216)では下関・長門の各圏域が1市だけとなるため、地理クイズの学習適性を優先して4地域を選んだ。

山口県の19市町を全国2026版索引に照合。

- 東部（とうぶ）：8区域
- 中部（ちゅうぶ）：4区域
- 北部（ほくぶ）：4区域
- 西部（せいぶ）：3区域

郡名：6町、4郡。根拠：[J-LIS 山口県内市町](https://www.j-lis.go.jp/spd/code-address/chuugoku/cms_15614184.html)。

ページは岡山県V2と共通の構成で、地域選択・一覧とクイズ1/2。共通地図・採点・表示エンジンは変更しない。検証版として noindex を維持。

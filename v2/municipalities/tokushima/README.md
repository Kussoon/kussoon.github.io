# 徳島県V2 地域学習・クイズ1/2

2026年11月10日。徳島県公式の行政上の3圏域（[東部・南部・西部](https://www.pref.tokushima.lg.jp/FAQ/docs/00038843/)）を採用。

- 東部（とうぶ）：15区域
- 南部（なんぶ）：5区域
- 西部（せいぶ）：4区域

合計24市町村。全域モードでは24問。郡名・読みは[J-LIS徳島県内市町村](https://www.j-lis.go.jp/spd/code-address/shikoku/cms_15714186.html)を基準に16町村・8郡を登録。

既存共通クイズJS・CSS、全国地図・ラベル・採点ロジックは不変更。検証版noindex。iPhone Safari実機確認は別途。

# 香川県V2

2026年11月10日。気象庁の[市町村等をまとめた地域](https://www.jma.go.jp/jma/kishou/know/yougo_hp/shichoson_ichiran.html)に従い、香川県を5地域（小豆・東讃・高松地域・中讃・西讃）に区分。

- 小豆（しょうず）：2区域
- 東讃（とうさん）：3区域
- 高松地域（たかまつちいき）：2区域
- 中讃（ちゅうさん）：8区域
- 西讃（せいさん）：2区域

全国2026年索引の17市町と一致。9町5郡の郡名・読みは[J-LISの香川県内市町一覧](https://www.j-lis.go.jp/spd/code-address/shikoku/cms_15814186.html)に照合。クイズ1・2とも全域17問対応。

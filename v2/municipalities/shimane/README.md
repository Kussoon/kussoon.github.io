# 島根県V2 地域学習・クイズ1／2

**学習区分：出雲・石見・隠岐の3地方（2026年11月9日変更）**

当初は県保健医療計画の7圏域（松江・雲南・出雲・大田・浜田・益田・隠岐）で実装したが、「出雲圏域」が出雲市のみとなり、場所当てクイズ1の出題が意味を持ちにくいため、歴史・地理上の3地方に統合。

[出雲市作成・厚生労働省公開の地域図](https://www.mhlw.go.jp/content/12300000/001490416.pdf)にある現行市町村の3地方を採用する。

- 出雲（いずも）6：松江市、安来市、雲南市、奥出雲町、飯南町、出雲市
- 石見（いわみ）9：大田市、川本町、美郷町、邑南町、浜田市、江津市、益田市、津和野町、吉賀町
- 隠岐（おき）4：海士町、西ノ島町、知夫村、隠岐の島町

2026年全国共通地図の県コード32、19区域を全件照合。**8市10町1村**。5郡・11町村の郡名・読み仮名は従来どおりで変更なし。

## 注意

- 歴史的な「出雲・石見・隠岐」と行政計画の「7圏域」は異なる区分。7圏域を3地方へ合算しただけで、19市町村の所属コードは変更・重複・欠落なし。
- 隠岐地方4町村については、地図の全体表示・拡大縮小を実機確認する。
- 共通クイズ・採点・4択・描画・ズーム、全国の地図データや他県の構成を変更しない。
- noindexの検証版として保持し、ユーザーの実機確認後に承認。

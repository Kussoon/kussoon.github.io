# 高知県V2

2026年11月10日。[高知県公式・第4期地域アクションプランの7地域（PDF 1ページ）](https://www.pref.kochi.lg.jp/doc/2019120600074/file_contents/file_2022421416538_1.pdf)を基準に学習用6地域を設定。

高知市地域は1市のみなので、3市の物部川地域と統合し「高知・物部川」（4市）として出題する。**高知県が公式に6地域を定めたものではない。**その他の安芸・嶺北・仁淀川・高幡・幡多の境界は県公式区分を維持。

- 安芸（あき）：9区域
- 高知・物部川（こうちものべがわ）：4区域
- 嶺北（れいほく）：4区域
- 仁淀川（によどがわ）：6区域
- 高幡（こうばん）：5区域
- 幡多（はた）：6区域

合計34市町村。全域クイズ34問。23町村6郡の郡名・読みは[J-LIS高知県内市町村](https://www.j-lis.go.jp/spd/code-address/shikoku/cms_16014186.html)を照合。2026全国索引とのコード一致を契約テストで確認。

共通地図・採点・JS/CSSは不変更。公開後iPhone Safariでの動作確認が必要。

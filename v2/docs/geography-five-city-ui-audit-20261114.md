# Kussoon V2「世界から町へ」｜5市共通UI・操作性監査（2026-11-14）

## 対象と判定方法

対象：`https://kussoon.com/v2/geography/`、西宮・宝塚・尼崎・伊丹・芦屋の町名一覧および地図への橋渡し。**対象は5市・721町名の現在の比較試作**であり、日本全市町村の画面や世界地図ではありません。

- 監査根拠：2026-11-14 mainの階層HTML/JSON、橋渡しHTML、既存GitHub Actions、`scripts/audit-geography-ui.cjs` のChromium/WebKit自動操作。
- 利用者確認：同日、ユーザーがiPhone Safariで操作し「正常に動いています」と報告。これは貴重な**利用者実機確認**だが、全5市・全721町・全機種の網羅検査とは区別する。
- 作業の原則：現行ページのHTML、データ、地図、URLを**変更せず**監査結果とテストだけを追加する。

## 1. 操作性の合格基準

1. 世界→日本→兵庫県→5市という順に利用者が画面のリンクを押してたどれる。
2. 各市の町名一覧で、漢字・読み仮名から検索でき、35件上限を維持する。
3. 町名を選択した後、元の階層に戻れる。
4. 画面の横スクロールが320 / 390 / 768 / 1280pxで意図せず発生しない。
5. PCでのキーボード操作（検索窓へのフォーカス、入力）が機能する。
6. 地図の既存操作、クイズ、点滅、町名数・例外は変更せず、全国V2の回帰検査を保持する。

## 2. コードレビューで確認した強み

- 5市共通の `index.html` で町名を表示し、読み仮名も併記。情報は `textContent` により描画し、外部データをHTML文字列として直接実行しない。
- 都道府県・市町村・町名の遷移はハッシュで実現。元の正式URLに変更なし。
- 町名を検索した際に対象件数と最大35件の表示件数を示し、スクリーンリーダー向け `role=status` を設定。
- 検索欄は `label` と関連づけられ、最低44pxの入力欄高さを確保。
- 画面幅620px以下では地域カード2列、町名カード3列に切り替える。
- 既存5市の地図そのものは再生成・再実装せず、各サイトの本来の挙動を維持。

## 3. 改善候補（現段階では仕様変更しない）

| 優先 | 論点 | 現状と検証根拠 | 次に行う比較試作 |
| --- | --- | --- | --- |
| 中 | 町名の読み仮名サイズ | `.town-grid .reading` が11px。スマートフォンでは読みづらい可能性。 | 12〜14px、カード高さ・3列を維持した比較 |
| 中 | 現在地の読み上げ | パンくずは全階層をリンク化し、`aria-current=page` がない。 | 現在地だけを現在地と認識できるマークアップに変更したA/B |
| 中 | 検索の表記揺れ | 現行は大小文字化と部分一致のみ。カタカナ→ひらがな・NFKC正規化に未対応。 | 検索の正規化だけを比較試作し既存結果を変えないことを確認 |
| 低〜中 | 画面読み上げ量 | `aria-live=polite` が画面全体のパネルに付く。更新時に冗長な通知の可能性。 | 読み上げ対象を状態テキストに限定する比較 |
| 低 | 町名リストが35件上限 | 上限自体は確定仕様。一致候補が36件以上の時、36件目以降は一覧から直接選べない。 | 検索誘導・候補数案内のわかりやすさを実機で観察 |
| 要調査 | iframe経由の戻る・スクロール | 尼崎・伊丹・芦屋の3市は、V2内のiframeに元の地図を読み込んでいる。 | iPhone Safari実機で長いページ・iframeスクロールを比較 |
| 要調査 | 特殊文字を含むハッシュURL | `decodeURIComponent` に対する不正なパーセント符号化はJS例外の可能性。現在の721町名の通常URLでは未確認の問題。 | 異常なURLの読み込みを安全に処理する防御だけを比較 |

※「改善候補」は現行サイトで実害を実機確認したという意味ではありません。既存の正規利用経路が正常に動くことと、より良いアクセシビリティの余地があることは両立します。

## 4. 自動操作・レイアウト監査の範囲

監査コード：`scripts/audit-geography-ui.cjs`

- **幅320px・390px**：iPhoneサイズのWebKitエミュレーション
- **幅768px・1280px**：Chromiumによるタブレット・PC幅
- 各幅で「世界→日本→兵庫県→5市→代表町名を検索→選択→町名一覧→兵庫県へ戻る」を5市分操作。
- 町名一覧のフォーカス・キーボード入力も追加確認。
- 地域一覧・町名一覧・町詳細の水平はみ出しを測定し、`aria-current`・読み仮名のサイズを記録。
- GitHub ActionsではJSON報告書とスクリーンショットを `geography-five-city-ui-audit` として14日保存する。
- ブラウザーでの地図連携とクイズの完全な回帰は従来の `scripts/smoke-nishinomiya-town-v2.cjs` も継続実施する。

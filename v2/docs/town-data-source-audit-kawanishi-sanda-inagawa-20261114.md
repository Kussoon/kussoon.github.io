# Kussoon V2｜川西市・三田市・猪名川町の町名マップ比較試作（2026-11-15更新）

## 目的と現状
PR #449の地域トップ共通テンプレートに続く、市町村町名マップの展開準備です。本PRでは川西市の独立比較試作を追加します。三田市・猪名川町は出典候補と接続基準のみで、元データ取得・地図作成は未着手です。

比較試作は `v2/kawanishi-town-pilot/` に置き、全国V2・既存5市の町名データとページを変更しません。正式公開やmainへの統合は行いません。

## 既存実装と保持事項
- 地域トップ試作: `/v2/region-top/`; データ: `v2/region-top/data/regions.json`
- 対象3地域の `status: planned`、`features: []`、`existingTop: null` を維持します。
- 既存5市（西宮321・宝塚125・尼崎140・伊丹76・芦屋59、合計721）の町名データ・地図は変更しません。
- 全国V2の `v2/national/MAINTENANCE_RULES.md` と確定仕様は変更しません。比較試作では読み仮名を初期OFFとし、検索候補は最大35件です。
- 住所階層「世界→日本→兵庫県→市町村→町名」と地域トップは別機能です。

## 川西市の境界データ
- 出典: [CODH/Geoshape 川西市 2020年国勢調査町丁・字等別境界データ](https://geoshape.ex.nii.ac.jp/ka/resource/28217.html)
- 取得ファイル: `v2/data/towns/kawanishi-2020.topojson`
- 元データURL: `https://geoshape.ex.nii.ac.jp/ka/topojson/2020/28/r2ka28217.topojson`
- SHA-256: `e3e1720bb4bdb3866047f2fe4d7ef4b3a99e900bdbab78764ed4fda4b2d6003f`
- ライセンス: CC BY 4.0。ページにCODH/e-Statの推奨クレジットを表示。

| 検査項目 | 結果 |
| --- | ---: |
| TopoJSON `town` レイヤー | 191統計ポリゴン |
| `city` レイヤー | 1市域境界（町名地図から除外） |
| 異なる `S_NAME` | 182表示名候補 |
| 一意な `R2KAxx_ID` | 191件 |
| 同名の複数ポリゴン | 7表示名、計9ポリゴン分の重複 |
| 空の `S_NAME` / ID | 0件 |
| 不正・開放リング、非有限座標 | 0件（191リングを検査） |

同名の複数区画は検索候補を1件にまとめ、地図形状と内部IDはすべて残します。`KEY_CODE`は同名区画間で重複するため、内部区画IDとして一意な`R2KAxx_ID`を使います。元データにはTopoJSONの`transform`がないため、座標をデルタ変換せずに読み込みます。

**191は統計ポリゴン数であり、182は統計データ上の表示名候補数です。いずれも現行の町名数を確定する値ではありません。**

## 読み仮名と現行町字の照合
- 読み仮名の照合元: [デジタル庁 アドレス・ベース・レジストリ](https://www.digital.go.jp/policies/base_registry_address)の町字データ（2026-06-23公開分）。個々の読み・区分の確認に[全国Q地図の川西市一覧](https://qchizu.jp/data/addresses/pages/%E5%85%B5%E5%BA%AB%E7%9C%8C/%E5%B7%9D%E8%A5%BF%E5%B8%82/)（ABRデータを表示）を参照。
- 川西市一覧は住所の町字149件と通称70件を掲載。CODHの182候補を漢数字/全角数字、ケ/ヶ、鴬/鶯、末尾「字」の表記差を正規化して照合しました。
- 川西市公式「住居表示実施区域一覧表」には101名称が掲載され、表記を正規化した結果、101件すべてCODH 2020候補に一致しました（うち3件は資料に一部未実施の注記あり）。この資料は住居表示実施区域だけを対象とし、全町字名簿ではありません。地名の照合結果を境界形状の一致とは扱いません。
- ABR読み照合の結果: 180件が一意に一致、2件が未照合。重複読み候補はありません。未照合は「一庫字北中島」「西多田字平井田筋」です。
- よって、読み仮名は180/182候補で照合できました。未照合12件には読みを推測して付けず、地図上の読みを空欄にします。

ABRの町字名・読みとの一致は、2020年統計境界が現行住所境界・住居表示区域と一致することを意味しません。ABR側に存在しない字名もあり、住所体系・通称・統計区画の単位が異なります。試作ページには2020年基準であることと現行境界を保証しない旨を表示します。川西市公式GISによる座標・形状の全域比較は未完了です。住居表示実施区域一覧表は名称照合にだけ使いました。残る不一致や境界の現行性を推測で補わず、正式データへ持ち込みません。

## 試作機能
- CODH 2020町丁ポリゴンのみを描画し、市域ポリゴンは除外。
- 同名の統計ポリゴンをまとめて一つの検索候補・ラベルにします。
- 地名と照合済み読みを上下2段で表示。読み仮名の初期状態はOFF。
- 地名・読み仮名検索、候補最大35件、区域選択、拡大縮小、ドラッグ移動、市全体への復帰。
- 名称選択時は、同名ポリゴン群の範囲へ移動。
- 地域区分は出典確認前に創作しません。町域ポリゴンの選択を区域選択として扱います。

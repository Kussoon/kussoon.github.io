# V2 特殊形状の町域に対応する汎用ラベル配置実験（2026-10-30）

## 目的

既に芦屋市で好評だった「町域中心・地名は1行・全件表示・境界またぎと重複を許容」を維持したまま、下記も**手入力のラベル座標なし**で処理する。

- **三日月・U字・C字・鉤形**：面積重心が町域外にあったり、重心とPolylabelを結ぶ直線が町域外に出たりする。
- **鹿児島県のような多数の枝と離れた小領域**：大きな本体＋細長い枝＋小島。
- **西宮市「一ケ谷町」「仁川町」**：一ケ谷町は1多角形。仁川町は地理資料上、仁川町一丁目～六丁目の**6つの区域**からなる。これらを1名「仁川町」としてまとめる場合の表示位置も検証する。
- **中央に穴のある町域**：面積重心が穴に入ってしまう。

## ルール（新しいオプション `anchor:'universal'`）

1. まず従来の `safeInteriorCenter` を使い、幾何学的重心の位置を確認する。重心が町域内でPolylabelの最大境界余裕の**26%以上**ある場合、前回ルールを**そのまま採用**する。
2. 重心が町域外・極端なくびれにある場合に限り、**最も面積が大きい外周リング**（主要部分）を選ぶ。島・丁目など複数リングを1つの地名に集約したとき、小さな離島へ飛び移らないようにする。
3. 主要部分の境界に囲まれ、かつすべてのリングについて偶奇規則で「内側」と判定できる点を候補とする。中央に穴がある場合、穴の中は排除する。点から本来の境界までの距離が、主要部分で現実に得られる最大距離の**35%以上**あることを目安とする。
4. 主要部分の外接矩形を24×24の格子に分割して2次元で探し、その後4段階の局所探索を行う。条件を満たす点の中から、**その主要部分の面積重心に最も近い点**を優先する。重心～Polylabelの直線上だけを探す旧方式とは異なる。
5. 従来の「水平の左右余裕が極端に非対称なときだけ補正」も併用する。周辺ラベルとの重なりでは町名を隠さず、縦長の隣接町の控えめな上下調整は独立したオプションとして残す。
6. ラベルアンカーは**町域形状だけ**から計算し、WeakMapに保存する。表示文字サイズ・ズーム・読み仮名モードを切り替えても基本アンカーは変わらない。

**意図**：全ての文字を町域に収めるのではなく、町域のどこかが分かり、拡大すれば文字が読めることを優先する。

## 比較と結果

独立試験ページ：[`/v2/irregular/`](../irregular/index.html)。芦屋市59町名にも、表示位置の追加選択肢として新方式を提供。ただし、好評だった現在の `smart` 方式を**初期値のまま維持**し、いきなり置き換えない。

| 形状 | 従来方式 | 新・汎用方式 |
| --- | --- | --- |
| 架空の三日月 | 一方の端へ寄ることがある | 重心に近い内側の帯状部分を2次元探索 |
| 架空のU字 | 下端や片脚寄りになる場合 | U字の底付近の内側を選ぶ |
| 架空の中央穴 | 穴の中央に重心が入る | 穴に置かず、周囲の内部を選ぶ |
| 架空の本体＋小島 | 幅のある小島が候補になり得る | 主要部分の面積を優先 |
| 西宮市・一ケ谷町 | 自然な重心 | **従来の位置を維持** |
| 西宮市・仁川町（6丁目分を集約） | 最大余裕地点へ遠く移動する傾向 | **六丁目の主要区域内で、重心に近い場所へ** |

この検証の「仁川町」は丁目を合わせた**合成の表示単位**であり、現在の西宮市サイトの正式町名ラベルを再定義したものではない。

### 実データの出典

- 出典：`Kussoon/nishinomiya/data/nishinomiya-towns.topojson` のCODH加工データ（令和2年国勢調査町丁・字等別境界データセット、**CC BY 4.0**）
- 検証用抽出先：`v2/tests/fixtures/nishinomiya-irregular.json`
- 抽出対象：一ケ谷町、仁川町一丁目～六丁目（六丁目は単独でも試験）
- 元の緯度経度をテスト用の平面座標に投影・拡大縮小して記録。**行政界の確定用地図としては利用しない**。
- 三日月・U字・鉤形・鹿児島県風・穴あき・細長い本体と小島は**架空の図形**。実際の鹿児島県界を使用していない。

## 回帰テストと受け入れ条件

`node --test v2/tests/universal-centers.test.cjs`

- 実データ3件と合成形状6件について、必ず町域内の安定した点を返す。
- 町域穴にラベル中心を置かない。多部分なら主要面積の形を選ぶ。
- 一ケ谷町は位置不変。仁川町は従来より主要部の重心に近い。
- 通常モードを変更せず、芦屋市59町名の現行配置が不変。新モードでも59町名を隠さない。
- 文字サイズや表示モードによって形状のみの中心が変化しない。

## 重要な制限と次の工程

- 最大面積部分を優先することが**常に最良ではない**。2つの同程度の面積の飛地を持つ町、行政上特別に重視したい離島・港湾区画等は、複数ラベル・優先区画の設定が必要になる可能性がある。
- 穴・飛地の境界と複数の丁目を「町単位で統合」するときは、内部共通境界の溶解や外周の整理が次の実装課題。今回の比較試験では丁目ごとの輪郭をそのまま用いる。
- このアルゴリズムが自然な位置を**保証するわけではない**。複雑地形の自動候補を大幅に改善するための実験である。iPhone画面で西宮市実データと芦屋市の回帰を確認してから標準採用を判断する。
- 現行 `/nishinomiya/`, `/ashiya/`, `/hyogo/` 等は編集していない。

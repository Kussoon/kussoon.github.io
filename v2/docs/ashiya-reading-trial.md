# 芦屋市 V2：読み仮名と1行上下微調整の比較（2026-10-30）

試験ページ：[`/v2/ashiya/readings.html`](../ashiya/readings.html)  
本体プログラム：[`/v2/common/js/readable-labels.js`](../common/js/readable-labels.js)

## 目的と背景

地名には読みの例外が多い。ユーザーが指摘した西宮市「美作町」は「みさくちょう」であり、一般的に連想しやすい「みまさかちょう」ではない。このため、地図は場所だけでなく**正しい読みも覚える教材**とする。

Yahoo!マップの住所レイヤーを参考に、地名自体は原則1行で表示し、縮尺によるラベルの選択と「上下へ半文字・1文字程度動かす」方式を試す。同時に「漢字のみ」「漢字＋小さな読み仮名」「ひらがなのみ」を切り替えられるようにする。

これはYahoo!マップの地図・アプリ・有料コンテンツを複製するものではなく、UI設計の参考にした独立実装である。

## 読み仮名データの出典と一致確認

- `Kussoon/ashiya` の既存 `town-search.html` には `{name,reading}` が**59件**あり、`/v2/data/ashiya/labels-source.json` の59町名と**59対59で完全一致**する。
- 読み仮名は**すべてひらがな**であり、欠落0件、重複0件。
- 読みの既存照合資料は日本郵便「郵便番号検索」。出典は [SOURCE_LEDGER.md](https://github.com/Kussoon/ashiya/blob/main/SOURCE_LEDGER.md) に記録。
- `v2/data/ashiya/readings.json` に地理形状と別に保存。元Git blob SHAを出典メタデータに記録する。
- 「業平町＝なりひらちょう」「大桝町＝おおますちょう」「剱谷＝けんたに」などの現行データをそのまま使用。
- 学習用地図の境界にはCODH由来の加工SVGを使用。形状・読みは別データ。今後新たな市に展開する際は読みの照合元を市ごとに点検する。
- 芦屋市の試作では町名をJSONキーにしているが、V2の汎用データ設計では**同名町の存在に備えて安定した地域ID**に移行すること（設計上の課題として残す）。

## 比較内容

| 表示モード | 地名ラベル | 文字寸法 |
| --- | --- | --- |
| 漢字のみ | 漢字地名を1行 | 画面上12～22 CSS pxから選択 |
| 漢字＋小さな読み仮名 | 漢字1行＋その下に小さなひらがな1行 | 漢字の約58％の文字サイズで読みを追加 |
| ひらがなのみ | 読み仮名を1行 | 画面上12～22 CSS pxから選択 |

「漢字＋読み仮名」は、**地名を意味的に2分割した2行表示とは別**。町名自体の改行はしない。

上下の微調整：基準のラベル中心を維持するか、重なる場合に上・下へ半文字／1文字／1.5文字分の候補を試す。横方向には動かさず、候補中心が対応する区域内に留まることを条件とする。衝突回避後も重なるラベルは縮尺に応じて一時的に非表示にできる。

文字寸法は画面の描画幅とSVG viewBoxを使ってCSSピクセルから変換する。漢字・読み仮名を合わせたラベル矩形を衝突計算に含め、漢字だけの高さで判定しない。

町名検索は漢字・ひらがな・カタカナ（NFKC正規化）に対応。検索語はブラウザ内でのみ処理し、ネットワーク送信しない。ラベルが省略されていても検索・地図選択から到達可能。

## ブラウザではない予備計算

59町名、全域表示、画面幅390 CSS px、文字16px、文字幅を1文字≒フォントサイズと仮定：

| 表示方式 | 上下調整なしの表示件数 | 上下微調整ありの表示件数 |
| --- | ---: | ---: |
| 漢字のみ | 24 | 25 |
| 漢字＋読み | 17 | 20 |
| ひらがなのみ | 18 | 21 |

この予備条件では表示中ラベル矩形の重複は0組。**ブラウザの日本語フォント寸法・描画結果・性能を保証する数値ではない。** また上下への微調整は「区域外」判定を改善する目的ではなく、他ラベルとの衝突を回避するための方法である。

## 実機での確認ポイント

1. 全域表示で、漢字のみ／漢字＋読み／ひらがなを切り替え、文字の大きさと読みやすさを確認。
2. 「上下移動なし」と「上下微調整」を同じ表示範囲で比較。とくに市街地密集部のラベル数・位置を観察。
3. 2～4倍に拡大し、表示する名前が増えるか、読みと漢字の対応がずれないかを確認。
4. 「なりひらちょう」「オオマスチョウ」の入力から検索・該当町選択・拡大が機能するか確認。
5. ピンチ、ドラッグ、PCホイールのB案と地図外クリックを確認。
6. 文字が区域からはみ出す赤文字判定だけで表示品質を決めない。重要なのは読みやすさ、位置の特定しやすさ、ラベル同士の重なり、全地名への到達性。

## 限界・次工程

- 1行を優先すると、漢字＋読みは広域で表示件数が減ることがある。将来は**ズーム別に読み仮名を表示／省略**するオプションも検討。
- 「ひらがなのみ」は漢字より長くなりがち。仮名を勝手に省略しない。
- ラベル矩形内・区域内評価は概算であり、隣接町の境界付近では赤い判定でも読みやすい場合がある。
- 本試作は芦屋市のみ。西宮市の読みは別途 `Kussoon/nishinomiya` の正本と照合し、事実確認してから適用する。
- V2正式導入時は読みの表示切替を地図、検索、クイズ、復習の共通設定として展開する。世界の国名等では表記体系が異なるため、読み／別名／現地語表記を別属性として管理する。
- 今回の試作は既存の `/ashiya/`、他市、本番トップを編集しない。PRは未マージのまま公開判断を待つ。

# Kussoon「世界から町へ」｜UI A/B比較試作（2026-11-14）

## 目的

2026-11-14の5市UI監査（PR #446）で改善候補として挙げた**2点だけ**を比較する。現在の正式稼働中の試作 `/v2/geography/` は変更しない。

- A（現行）：町名カードの読み仮名 `11px`、パンくずに現在地の `aria-current` なし。
- B（候補）：町名カードの読み仮名 `13px`、パンくずの現在地に `aria-current="page"` 追加。

対象は5市・721町名。町名データ、検索（最大35件）、地図へのリンク、C版、ブリッジ、クイズ、全国地図の動作を変えない。

## 試作URL

- [比較ページ（PCは左右、iPhoneはA/B切替）](/v2/geography/ui-comparison.html)
- [A・現行](/v2/geography/)
- [B・候補](/v2/geography/ui-candidate.html)
- [B・西宮市町名一覧](/v2/geography/ui-candidate.html#towns:jp-hyogo-nishinomiya)

AとBは現行の町名索引・元の5市の地図を同じように読み込む。比較ビュー内の検索・移動は相互同期せず、市の選択変更時にだけ両側の表示を揃える。

## 変更する規則

1. **読み仮名の文字サイズ**：`.town-grid .reading` のみ11→13px。他の読み仮名・文字の大きさ、町名ボタン高さ・幅、スマホ3列、PC4列は変更しない。
2. **パンくずの現在地を読み上げられるようにする**：現在の段階だけを `<strong aria-current="page">` にし、それ以前はこれまでどおりリンクを残す。町名詳細では末尾の町名が現在地、町名一覧では「町名」、自治体・県・国などではその名称を現在地とする。既存の戻るリンクは維持する。
3. Bの試作識別用タイトル・比較ページへの戻りリンクのみ追加。正式URLへの誘導や既存C版の動作・更新日時には影響させない。

## 検証・採用基準

- `node v2/geography/test-ui-comparison.cjs` で、現行から候補Bへの差分が2点＋試作の識別表示に限定されていることを照合。
- `scripts/smoke-geography-ui-comparison.cjs` で320・390・768・1280px、5市、現行A・候補Bの町名一覧・検索・町名詳細・戻り・地図リンクの同一性・横はみ出し・35件上限を確認。
- 文字サイズが13pxのときもカード高さ44px以上、ページ全体に意図しない水平スクロールが生じないこと。
- Bの現在地はパンくず内で常に1個だけ `aria-current="page"` となり、正しい現在地を指すこと。
- 既存の5市ブラウザーテストと全国V2回帰テストを維持する。
- iPhone Safariの実機で読みやすさ・VoiceOver読み上げを確認してから正式採用する。この比較PRをマージしても**Bの正式採用にはならない**。

# 西宮市V2：縦長で隣接する町名の回帰テスト

更新：2026年10月30日

## 長期的な検証対象

次の6町名を、今後V2の自動配置規則を変更する際の**恒久的な回帰テスト**として維持する。

1. **鞍掛町（くらかけちょう）・久保町（くぼちょう）**
2. **上ケ原七番町（うえがはらななばんちょう）・八番町（うえがはらはちばんちょう）・九番町（うえがはらきゅうばんちょう）・十番町（うえがはらじゅうばんちょう）**

漢字の「上ケ原」は町名データの表記に準拠する（一般的な「上ヶ原」と混同しない）。ユーザーは「そこにラベルがあるとわかればよい。重なっていても隠さない。読めなければ拡大する」ことを優先する。

## 出典・試験データ

- 形状：`Kussoon/nishinomiya/data/nishinomiya-towns.topojson`（CODH令和2年国勢調査町丁・字等別境界加工、CC BY 4.0）。
- 読み：`Kussoon/nishinomiya/town-search.html` の既存 `name/reading` データ。
- リポジトリの出典Git blob SHAは `v2/tests/fixtures/nishinomiya-adjacent.json` 内に保存。
- 鞍掛町／久保町を含む周辺**19町域**と、上ケ原七〜十番町を含む周辺**30町域**を、独立して試験用SVG座標に投影・正規化。
- これは境界の確定用データではなく、既存の地理データから抽出した**自動配置回帰テスト用の固定スナップショット**。市域全体を置き換えるものではない。
- `v2/nishinomiya/staggers.html` は差分を目で比較する独立試験ページ。

## 現行のルールをこのまま適用

- `planCenterFirstLabels(...,{anchor:'safe',shift:'adjacent'})` を使用。町域中心を優先し、幾何学的重心が不適切な場合のみ安全な内部点へ補正。
- 両隣が南北に細長く、主文字が重なっている場合、**上下半文字〜1文字**の候補を自動選択。移動の前後で他ラベルの重なりが悪化しないことを条件にする。
- **横へずらすことで隣との重なりを避けない**。現在の水平補正は町域内部での左右余裕の極端な偏りだけに適用。
- 全町名を必ず表示。衝突による表示省略なし。漢字と読み仮名を併記しても、**漢字の中心は漢字のみと同位置**。

## 数値の再現条件・期待値

それぞれの対象町域グループの外接矩形を最大800 SVG単位に正規化し、画面幅390 CSS px・漢字18px、文字幅を簡略的に1文字＝フォントサイズとして計算。

| 対象 | 相当縮尺 | 上下調整なしの重なり組数 | 自動上下調整後 |
| --- | --- | ---: | ---: |
| 久保町・鞍掛町 | 1倍 | 1 | **0** |
| 久保町・鞍掛町 | 2倍 | 0 | **0** |
| 上ケ原七〜十番町 | 1倍 | 3 | **1** |
| 上ケ原七〜十番町 | 1.5倍 | 1 | **0** |
| 上ケ原七〜十番町 | 2倍 | 1 | **0** |

久保町は初期の広域相当で約1文字下へ、上ケ原八番町・九番町は約半文字〜1文字上下へ移動。対象は**非表示なし**。対象地域の外の周辺町名も配置計算の対象に含める。

検証方法：`node --test v2/tests/nishinomiya-staggers.test.cjs`

回帰で必ず確認する事柄：
- 6町名と読みの正確な対応、および周辺モデルの件数。
- 自動調整後の重なりが増えないこと。現状の問題箇所の重なりが改善されること。
- 横へ押し出す移動なし、町域内にアンカーが存在し、町名を一つも隠さないこと。
- 漢字のみ／漢字＋読み仮名のアンカーと主文字寸法の同一性。
- 拡大時に対象6町名のラベルが見えること。

## 限界・今後の適用

- 試算値は**ブラウザ実測ではない**。iPhoneの実際のフォントとレンダリングで見た目を比較すること。
- 隣接する町域を増やしたり、文字サイズを変えたりすると、上下微調整の結果は変わり得る。
- 1.5倍で久保町・鞍掛町の重なりは残る場合があるが、2倍で解消する。**全ての倍率で重複ゼロを目標にしない**。
- 将来、他市や兵庫県49区域へ展開する際にも、この回帰テストを継続。すべての行政単位が単一の連結多角形とは限らず、飛地や複数リングの例は `v2/tests/universal-centers.test.cjs` で別に確認する。
- 正式ページ `/nishinomiya/`、`/ashiya/`、`/hyogo/` は変更しない。試験ページには noindex・Umami・共通フッターが必須。

# Kussoon V2｜世界から町までの地域階層・試作仕様 v0.1

作成：2026-11-14  
対象：`/v2/geography/`（試作、`noindex`）  
参照元：[`v2/docs/design.md`](design.md)、[`v2/docs/roadmap.md`](roadmap.md)、[`v2/README.md`](../README.md)。既存の `MAINTENANCE_RULES.md` および正式全国地図の表示仕様は変更しない。

## 1. 目的と確定している前提

- 利用者は **世界 → 国（日本） → 都道府県（兵庫県） → 市区町村（5市） → 町名** という順でたどれる。
- 今回は**ナビゲーションの試作のみ**。47都道府県すべて、世界の国すべて、市町村の全件はまだ収録しない。画面上でもその旨を明示する。
- 既存の `/nishinomiya/`、`/takarazuka/`、`/hyogo/` 等は移動も改名もしない。
- 現行の `/maps/national-municipalities.html` は引き続き全国地図の正本。試作は既存ページへの**入口**であり、地図の描画処理を複製しない。
- `/v2/` は公開される試験環境なので `noindex`、Umami、共通フッター、出典への配慮を維持する。

## 2. 異なる3種類の構造

| 種類 | 本案の扱い |
| --- | --- |
| 利用者向け階層 | 行政上の親子関係を画面のパンくずとリンクで表す |
| 公開URL | 現行を維持。将来の候補 `/atlas/` は**未採用**。試作URLは `/v2/geography/` |
| GitHub構造 | 既存6地域リポジトリを維持。サイト本体に階層索引のみ追加。実データ移動は行わない |

## 3. 試作階層（実在する入口のみ）

```text
世界
└─ 日本
   └─ 兵庫県
      ├─ 西宮市 ─ 321町名の検索・読み仮名一覧（元データ参照）
      ├─ 宝塚市 ─ 既存の町名検索へ
      ├─ 尼崎市 ─ 既存の町名検索へ
      ├─ 伊丹市 ─ 既存の町名検索へ
      └─ 芦屋市 ─ 既存の町名検索へ
```

**補足：** 県内にはこの5市以外にも市区町村がある。ここは試験収録範囲の一覧であり、兵庫県の行政区域の全件ではない。日本以外の国や兵庫県以外の都道府県は、実データのあるときに追加する。全国マップへのリンクは既存ページを使う。

## 4. データ形式

索引：`/v2/geography/data/hierarchy.json`。1レコードは `id,name,reading,kind,parentId,children,groups,links` を持つ。

- `id`：表示名とは独立した固定ID。今回の `jp-hyogo-nishinomiya` などは設計書の例に合わせる。全世界向け行政コードとの厳密な対応は、拡大時に別途照合する。
- `parentId`：原則一つ。世界のみ `null`。画面のパンくずはこの関係だけで構築する。
- `children`：試作内に実在する子ノードIDのみ。全行政区域の一覧を意味しない。
- `kind`：今回の値は `world, country, prefecture, municipality`。将来は `ward,town,chome` などを増やす。ただし国によって行政階層が異なるので「都道府県」を全世界の必須階層にしない。
- `reading`：この試作では全8ノードに付与し、常時表示する。
- `groups`：複数所属できる学習・生活圏の別キー。今回は5市に `hanshinkan` を例示。階層の親子関係を変えない。
- `links`：確認済みの既存URLへのリンク。実際の地図・クイズの正本はそこに置く。
- `townData`：現行の町名地図データへ接続できる市だけに設定する。

## 5. 町名・コミュニティの扱い

- 西宮市の町名一覧は `/v2/data/nishinomiya-town-v2-premerged.topojson` から**321件の町名**を読み、`/nishinomiya/data/maniac-readings.json` を参照して**読み仮名を併記**する。町名と読みをこの索引に再コピーしない。
- 町名の検索は入力した漢字・読みで絞り込み、最大35件表示。検索はブラウザ内で処理する。
- 一覧の町名を選ぶと名前と読みが分かる。ただし現在は**地図上で当該町域にズームしない**。その旨を画面で明示し、既存の町名地図・検索へ案内する。
- 宝塚・尼崎・伊丹・芦屋の町名データは今回は取り込まず、既存の検索ページへ案内する。存在しない町名一覧を作らない。
- 上甲東園は町名学習上は1町として扱い、C版のコミュニティ別表示のみ丁目単位で切り替える。
- 岡田山は上ヶ原・広田の両学習グループに所属するが、行政上の町名ノードは一つ。住居表示の番地境界を推定して分割しない。
- **将来の正式な町・丁目ID**は名称だけではなく、地域固有のコードや出典時点を含めて導入する。この試作の `#town:` は表示ナビ用であり長期安定IDではない。

## 6. 今後の拡張ルール

1. 次の県・市区町村を追加するときは、まず親IDと既存リンクの存在を確認し、`hierarchy.json` に最小限の新ノードを追加する。
2. 町名一覧は共通レンダラーを用い、各市のデータ形式差は `townData` で吸収する。市別のHTML/JS複製はしない。
3. 親子関係と学習グループ、地理図形と地名、表示用ラベルと読みを別管理する。
4. 新しい正規URL、SEO、古い公開ページのリダイレクト等は**別の決定**とする。既存リンクを壊す一括移動は行わない。
5. 公開正式採用には外部リンク確認・データ件数・町名読み・アクセシビリティ・スマートフォン操作・サイトマップと計測の回帰確認を要する。

## 7. 試験方法

- `node v2/geography/test-hierarchy.cjs` で階層の循環、孤児、重複ID、読み仮名、リンク形式、参照先の存在・HTMLの試作フラグを検査する。
- ブラウザーで世界→日本→兵庫県→西宮市→町名検索→町名を選ぶ→パンくずで戻る、他4市の既存ページリンクを確認する。
- iPhone Safariで町名検索の表示幅と入力動作を確認する。**コード検査だけで実機合格とはしない**。

## 8. URL・配置の保留事項

将来の公開用 `/atlas/` の採否、47都道府県・世界各国の網羅化、全市町村の町名安定IDの統合、各地域リポジトリの再配置は**本PRでは決定しない**。新設試作へのリンクは直接URLを案内する。既存トップや正式サイトのナビゲーションは変更しない。


## 2026-11-14 追補：宝塚市の125町名を第2市として接続

- 地域階層の既存5市を維持したまま、宝塚市に `townData.sourceKind = "town-info-array"` を設定。市別の別HTMLやJSの複製は行わず、西宮市と同じ町名一覧・検索画面を使う。
- 宝塚市の既存 `/takarazuka/data/takarazuka-town-info.json` の125町名と読み仮名を参照。表示時の検索は最大35件。
- 町名を選択すると `/takarazuka/town-search.html?q=町名` に遷移する。既存の検索ページは候補が1件のときのみ自動選択・点滅し、複数候補は利用者が候補を選択する。**西宮市C版と同じ確実な1町への直接フォーカスではない**ため、画面の説明も区別する。
- 元のTopoJSONは398図形、丁目集約後の町名台帳は125件。境界元データの「布売自由ガ丘」は従来サイトの正規化に従い「売布自由ガ丘」と扱う。他市へ無条件にこの補正を適用しない。
- 旧ページや宝塚市リポジトリを改変しない。次の市の追加は同じ `townData` アダプターを増やし、差分検査する。
- 回帰：西宮市321件、宝塚市125件、既存町名検索のクエリ受信、PC・iPhoneサイズWebKitの階層連携を検査する。実機Safariは別途確認。

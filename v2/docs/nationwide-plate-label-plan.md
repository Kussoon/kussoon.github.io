# 全国ナンバープレートマップ・市町村ラベルV2移行計画

調査日：2026年10月30日

## 前提

現在のサイト：`/driving/vehicleregistrationplates/region/`

GitHub上の構成は47都道府県別HTML＋`region/index.html`。都道府県別47ページのファイルサイズを集計すると、**合計108,565,546バイト（約103.5MiB）**。各県のHTMLは約1.4〜4.9MBで、全47ページをまとめて置換することは避ける。

重要：ユーザーの依頼はまず**市町村名表記・ラベル配置**の改良。ナンバープレート地域名の管轄、導入年月、地図上の色、クイズ判定、行政区分の変更ではない。既存データや法律面の記載を意図せず書き換えない。

## V2で共通化する部分

1. **安定ID：5桁行政区域コード＋県コード**を正本とし、町名テキストのみをキーにしない。同一文字列や政令市の区、飛地にも対応できるようにする。
2. 地理データは都道府県ごとにロードし、正しい出典と更新日・ライセンスを記録する。GeoJSON/TopoJSONなどの形状からV2の共通モデルに変換する独立アダプターを設ける。
3. 位置決めは**市町村区域の中心に置き、細いくびれ・三日月・飛地・穴あき形のみ自動補正**。文字全体の境界内収容は要求しない。
4. **全市町村名を表示**。重なりを許容し、拡大時に可読性が改善することを重要な受け入れ条件とする。隣接する縦長区域のみ自動の上下微調整を選択可能。
5. ナンバー地域名／色分けは既存データから分離し、行政IDによって区域へ結びつける。ラベル中心座標・判定ルールと混合しない。
6. 漢字＋読み仮名は**読みが確実に確認できた場合のみ**。まず漢字のみで進め、表示のために読みを自動捏造しない。
7. どの県を開いても同じ表示設定・検索操作とする。県境は標準では接続せず、都道府県別で必要な形状のみを遅延ロードする。

## 段階的な導入

**第1段階（実装中）：兵庫県49区域**

- `/v2/hyogo/labels.html` に現行ゲーム用とナンバー用の表示用途切替を作成。
- 49区域のTopoJSONに対して同じ座標計算を適用。
- 現行の `/hyogo/study-all.html` と `/driving/vehicleregistrationplates/hyogo-number-map.html` は変更しない。
- 全件表示、文字サイズ、神戸市9区、県内海岸・離島、色分け、iPhone操作を比較。

**第2段階：全国ナンバープレートマップの兵庫県ページに接続**

- `/driving/vehicleregistrationplates/region/28hyogo.html` のデータ依存・UI・市町村ラベル部分を監査。
- 本番HTMLを直接書き換える前に、`/v2/plate/28hyogo/` の独立した試験画面を用意する。
- 旧HTMLのHTML/JSON/SVGの境界データを必要に応じて分離し、地図上の管轄表示と制度説明を保持する。
- エッジケースとして神戸市の9区、淡路市・洲本市・南あわじ市、姫路市・西宮市の複数地図面を重点確認。

**第3段階：5県程度で回帰検証を拡張**

- 北海道（多数の区域・飛地）、東京都（23区、島嶼）、長崎県（離島）、鹿児島県（本土＋諸島）、沖縄県（広域島嶼）を優先して、単一県の形から推定できるか評価。
- それぞれの版で、行政区分名・ナンバーの管轄・島の表示優先順位は独立したデータ検証を行う。
- すべての県で同じテスト契約に従う：コード・件数・区域内中心・全件描画・拡大／縮小・検索・ライセンス・Umami／共通フッター。

**第4段階：残る県へ段階展開**

- 都道府県のHTMLを一括変換しない。共通エンジンと都道府県別データを利用し、各県の表示変更差分を最小化する。
- 旧URLを維持し、差分・スクリーンショット比較・GitHub Pages公開検証を経て移行する。
- もし特定の変形町域だけ自然に置けない場合、手動位置指定は例外扱いとして原因を記録し、共通ルールを先に改良する。

## 調査上の注意

- 47ページ合計103.5MiBという数値は、GitHub treeのHTMLファイルサイズの合計である。**ページの実通信量やGeoJSONデータだけのサイズを意味しない**。
- 47ファイルの内部仕様をすべて監査したわけではない。次の段階で兵庫県ページを対象に、埋め込みデータ・ラベル処理・外部リソースを詳細に分離する。
- 全国のナンバー地域名と運輸支局管轄の正しさは、将来の公式資料照合が必要。今回のV2ラベル実験では既存の制度判断を再確定しない。

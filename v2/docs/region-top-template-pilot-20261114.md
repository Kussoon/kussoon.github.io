# Kussoon V2｜地域トップ共通テンプレート比較試作（2026-11-14）

## 目的と公開範囲

「世界 → 日本 → 兵庫県 → 市町村 → 町名」の階層ナビゲーションと、地域の各種コンテンツへ進む**地域トップページ**は別の機能として扱う。町名地図を今後兵庫県全市町村へ広げる際に、市町村ごとに固有HTMLや地図実装を作り直さないため、共通テンプレートを比較試作する。

比較試作：`/v2/region-top/`（初期表示は西宮市）  
地域を指定：`/v2/region-top/?region=jp-hyogo-kawanishi` など。

**試作は `noindex`。既存の `/hyogo/`・`/nishinomiya/`・5市のトップ、`/local/`、`/v2/geography/`、全国V2、元の町名図やクイズを一切変更しない。**

## 役割の分離

| 入口 | 役割 | 存続する現行ページ |
| --- | --- | --- |
| `/local/` | 地域の学習・店舗・その他の地域記事への入口 | そのまま |
| `/v2/geography/` | 世界→日本→兵庫県→5市→町名という地理的な親子関係 | そのまま |
| `/hyogo/` | 兵庫県の全域地図・学習・クイズ | そのまま |
| `/nishinomiya/` など | 地域固有のコンテンツと特別な案内 | そのまま |
| `/v2/region-top/` | **機能がある地域だけカードを自動生成する共通地域トップの比較試作** | 新規。正式ページではない |

## データ構造

`v2/region-top/data/regions.json` の地域レコードを追加・編集するだけで、同じ `v2/region-top/index.html` が地域トップを生成する。

- `id`：上位の地理階層と一致する自治体IDを基本とする。現行5市のIDを変更しない。
- `name`、`reading`：表示名と読み。
- `kind`、`parent`：県・自治体の違いと親。
- `status`：`existing`＝元サイトに既存トップがある、`planned`＝今後追加候補でトップ・町名図を未接続。
- `existingTop`：すでに存在する地域トップのURL。存在しない場合は`null`にする。
- `geographyId`、`townCount`：既存の階層で町名検索が利用できる場合だけ指定。
- `features[]`：**利用できることが確認された**リンクのみ表示。未対応のクイズ・地図を見かけだけ作らない。
- `description`：短い地域案内。未整備の場合は試作状態を明記。

## 全国展開前に確定させること

1. 既存西宮市トップと新テンプレートを実機で比較し、見落とす機能がないか、初めての利用者にわかるかを確認する。
2. 川西市・三田市・猪名川町の町名境界・読み仮名・出典を個別に調査し、データが揃ってから`status`や機能リンクを増やす。
3. 神戸市については政令指定都市の区（神戸市→区→町名）を別途階層に導入し、市全体と区別の地域トップの関係を比較する。
4. 元サイトを新しいテンプレートに置き換えるか、共存させるかは現段階で決めない。既存URLの恒久的維持と、将来のSEO・ナビゲーション設計を別途検討する。
5. `v2/region-top/test-template.cjs` で9地域の構造・既存5市721町名・出典があるリンク・未接続地域の安全性を検査する。`scripts/smoke-region-top-template.cjs` で320/390px WebKit、768/1280px Chromiumの表示・タップ・リンク数・横はみ出しを確認する。

**比較が確定するまで、既存の市町村のトップを上書き・リダイレクト・複製したものとして正式公開しない。**

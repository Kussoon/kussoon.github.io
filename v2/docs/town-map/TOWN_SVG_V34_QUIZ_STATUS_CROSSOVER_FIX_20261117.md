# 西宮市町名SVG 第34比較版｜クイズ間の中断案内残存修正

2026-11-17。iPhone Safari実機画面で、クイズ1を途中終了してからクイズ2の1問目に正解した際、クイズ2の上に「中断した問題：『仁川町（にがわちょう）』を黄色く点滅表示しています。」という**クイズ1の案内**が残存した。

原因：`finishQuiz(true)` が意図どおり `#status` に中断案内を表示するが、次の `startQuiz(mode)` で `stopQuiz(false);stopBlink();` を実行しても `#status` のテキストは消去されない。地図の点滅とクイズ結果はリセットしていても、独立した案内DOMに以前の表示文字列が残った。

修正：**SVG第34比較ページの `startQuiz()` だけ**で `#status` の案内を「クイズ1を実施中です。」「クイズ2を実施中です。」へ切り替える。前回クイズの中断案内は新しいクイズに引き継がれない。地域選択や中断結果表示そのものの仕様を変えず、正式Leaflet C版・共通地図エンジン・描画配置式を変更しない。

再発防止：Chromiumデスクトップ、WebKit 390px/320pxで、クイズ1→中断→クイズ2開始→正答の間、旧案内が残らないこと、逆方向のクイズ2→中断→クイズ1開始でも残らないことを確認。既存の15段階UI遷移と321町名×クイズ2種の検査も合わせて実行。

比較用ページなので本PRの検査合格後に**比較HTMLのみ**をmainへ反映する。正式C版への切替は行わない。

# Kussoon V2町名マップ｜既存成果物継承の横断監査（第1次）

監査開始：2026-11-15 ／ 対象：川西市共通試作 `/v2/town-map/?code=28217` ／ **判定：全面継承未達、機能追加を停止**
 
> これはコード・既存文書の第1次差分調査。実機・ブラウザ全機能検証、全PRの確定仕様照合は未完了。推定をPASSにしない。

## 1. 最初に解消した誤解
PR #445「阪神間5市721町名の共通標準仕様」が統一したものは**「世界→日本→兵庫県→5市→町名」の階層ナビゲーションと既存地図への接続**であり、5市の地図エンジンの完全統合ではない。実際、現行標準 `v2/docs/geography-five-city-standard.md` は町名の取り込みを3種類、元の地図への移動を3種類と規定し、元サイトの表示・点滅・クイズ・操作は原則**変更しない**とする。

一方、PR #452以降の川西市は `v2/common/js/town-map-engine.js` という**新しいSVG町名アダプター**を、既存全国版 `label-engine.js` と `map-viewport.js` に接続した。西宮市B/Cが利用する Leaflet `L.map`・`L.tooltip` の地図表示、既存5市の地図操作や特殊例外を移植したわけではない。「既存5市の成果を生かした共通町名地図の完成」とは判定できない。

## 4. 重要な実際の差異
- 西宮B/C：Leaflet の常時 tooltip を用い、ラベルの複数配置・個別オフセットを持つ。基本文字サイズはLeafletの表示ズームに連動。これは手作業位置指定を他市へ複製すべきという意味ではない。
- 西宮C：地域選択・クイズ・同一町再タップで点滅停止、500ms周期の点滅等がコード上にある。
- 川西市：DOM の新規SVG `text` を毎回組み立て、全国版のラベル衝突選択関数を町名に適用。**文字幅の大きい町名を全国市区町村の低密度前提で間引くため、現状の画面が破綻**。
- 5市の元サイトは見た目・エンジン・データ元形式がそれぞれ異なる。従って「5市描画エンジンをそのまま持ってくる」だけでは統一共通エンジンは完成しない。

## 5. 開発停止ゲート（解除条件）
**現在は実装機能の追加・正式採用を保留する。** 次を終えるまで、ラベルだけの小変更を積み重ねない。

1. 既存5市全ページと西宮B/Cを機能別に監査し、出典コード・採用PR・例外・テストを一覧化。
2. `MAINTENANCE_RULES.md` の実ファイルと優先順位を確認し、全国V2／5市階層／町名地図の適用境界を明文化。
3. 川西市に必要な**初期必須機能**と**将来の学習・クイズ機能**を分離し、既存確定仕様を無断変更しない。
4. 新しい比較実装案を、既存の正式ページを動かさず `/v2/` 上でA/B比較。手作業ラベル配置を一般解としない。
5. 地図全体・南北・市街地・ズーム・検索・読み・選択・ホイール・タッチの画面証拠を取り、旧基準との差を確認。
6. 回帰CIに**川西市そのものの実ブラウザ検査**を追加。全国版CI PASSを川西市PASSと呼ばない。
7. 利用者がiPhone Safariで受け入れた後、正式採用を別判断する。

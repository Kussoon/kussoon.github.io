## 検査結果（2026-11-17）

[GitHub Actions run 44043829732](https://github.com/Kussoon/kussoon.github.io/actions/runs/44043829732) **PASS**、PC Chromium1280 / WebKit390 / WebKit320でC版のTooltip文字中心とSVG V25の実文字中心・町域基準点を比較。

- 初期市全体の町名：C/SVGとも基準点に対して左方向に文字幅半分、上方向約5px。初期表示の良好な近似を再確認。

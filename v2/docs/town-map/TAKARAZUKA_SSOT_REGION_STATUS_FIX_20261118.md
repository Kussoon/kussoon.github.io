# 宝塚市｜地域選択へ戻った際のクイズ案内残存を最小修正

正本：`TOWNMAP-SSOT-001`、R-TOWN-01/02/04/24/30〜35/42/44。2026-11-18。

[診断PR #593](https://github.com/Kussoon/kussoon.github.io/pull/593)、[run 44175573300](https://github.com/Kussoon/kussoon.github.io/actions/runs/44175573300) で、クイズ1/2の誤答・再挑戦・採点は3環境で合格。一方、クイズ2途中終了→「地域選択に戻る」→仁川地域へ変更のとき、以前の「中断した問題」案内が残ることを全3環境で確認した。

**根本原因**：`finishQuiz(true)`が意図どおり`#status`に中断町名を表示するが、`stopQuiz(true)`から呼ばれる`showCommunity()`では`#status`を更新しない。クイズ中の新規`startQuiz()`による消去は既にPR #589で採用されている。

**独立比較試作**：`v2/takarazuka-town-svg-ssot-region-status-20261118-pilot.html`。元の最新比較ページ`...quiz-crossover...`をコピーし、`showCommunity()`で現在の学習範囲を表示する一行だけを追加した別JSを読み込む。地域選択へ戻った後や地域変更後は「宝塚市全域を表示しています。」「仁川（にがわ）を表示しています。」等へ案内更新。地図描画・ラベル候補・地域読み・クイズ採点・ボタン・町域・データは変更なし。

自動検査：既存の誤答/再挑戦/中断全操作テストを更新し、**戻ると地域変更の双方で旧案内が残らないことをassert**。Chromium1280・WebKit390/320の3環境と、既存125町名×クイズ1/2の全問正答・20地域検査を実施。

今回の比較HTML/JSは、主版への即時置換ではなく、旧ページと並存する独立試作。成功後に主版として採用する場合はユーザーの採否と正本の変更記録が必要。正式宝塚市URLへは変更なし。

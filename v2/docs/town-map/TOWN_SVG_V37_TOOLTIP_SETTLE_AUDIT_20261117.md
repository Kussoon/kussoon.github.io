# 西宮市SVG V37｜Leaflet C版の旧Tooltip残存を時間軸・レイヤー所有権で検証

2026-11-17。V36 PR #581の26地域連続監査 [run 44047175030](https://github.com/Kussoon/kussoon.github.io/actions/runs/44047175030) で、C版は市全体から上ヶ原へ切り替えた直後にTooltip DOMが325件で残る（SVG V34は18件）。C版の対象ラベル19件、SVG18件で、C版上甲東園ラベルが元の全市版と地域版の2件同時に存在することを確認。以降の地域でもC版は無関係なTooltip DOMが数十件残り、V36の画面内文字表示件数差とV34監査の大きな外れ値の原因になっている可能性が高い。

V37は**C版だけ**に一時的な読み取りhookを入れ、市全体→上ヶ原→今津→市全体→上ヶ原の順に操作し、直後・50ms・300ms・800ms・500msでTooltip DOM数、上甲東園の表示数、町名レイヤー所有権、map.hasLayerを測る。Cの初期町名ラベル数324件と比較して、時間経過で古いTooltip DOMが消えるのか、レイヤー上の永続的な残骸なのかを判定する。

**重要な判断基準**：Leaflet C版に既存の表示不具合が実在する場合でも、原則としてC版を変更せず、正式SVG版に不要な重複表示を移植しない。大きな位置差が古いCラベルを対応付けた測定アーティファクトなら、比較監査の基準を「現行地域で有効なラベルだけ」に改める。ただしC版の表示と異なる箇所は、実機検証前に明示する。

## 監査の最終結果（2026-11-17）

[Run 44048484422](https://github.com/Kussoon/kussoon.github.io/actions/runs/44048484422) **PASS**。Chromium1280 / WebKit390 / WebKit320 の3環境で共通の結果：

| 操作からの経過 | C版Tooltip DOM数 | そのうち地図に未登録の旧Tooltip |
|---|---:|---:|
| 初期の市全体 | 324 | 0 |
| 上ヶ原切替直後 | 325 | 307 |
| 50ms後 | 325 | 307 |
| 300ms後 | 18 | 0 |
| 800ms後 | 18 | 0 |
| 今津切替直後 | 33 | 18 |
| 今津切替500ms後 | 15 | 0 |

上ヶ原切替直後の上甲東園は、`map.hasLayer=false` の旧市全体Tooltipと `map.hasLayer=true` の地域用Tooltipが同時にDOMに存在。300ms後は地域用1件だけが残る。戻って再度上ヶ原を選択した場合も500ms後に正常な18件へ復帰。

**結論**：従来の「上ヶ原19対18件」「上甲東園位置差最大47.897px」は切替途中の古いC版Tooltip DOMを誤って比較した監査上の外れ値。SVGにこの過渡的表示を再現する必要なし。実装コードの位置補正を増やさず、比較監査だけを安定後の描画と現在mapに登録されたTooltipに限定する。PR #583 (V38) に厳密な合否テストを追加した。C版そのものの変更は行わない。

# 西宮市SVG V32：地域選択・全体復帰における不要な再配置処理の削除

2026-11-17。PR #576 V31監査 [run 44042647660](https://github.com/Kussoon/kussoon.github.io/actions/runs/44042647660)は3環境でPASS。再配置を起動する呼び出し元は地域ボタンの `button.onclick`（V28/V30の元HTMLの195行目）と確定。地域ズームの `onZoom` では `sourceEvent=null` なので再配置呼び出しなし。V30の自動ズーム除外が効かない理由が確定した。

## 最小修正内容

V28から独立コピー。地域選択ボタンで明示的に呼び出していた `cLabelReflow()` を除外する。さらに「市の全体／区域全体」ボタンの `cLabelReflow()` も除外。地域選択や全体復帰では初期ラベル配置モードを維持する。よみONでは既存のRange測定に基づく再配置を維持し、よみOFFではV28の初期配置復元を維持。手動拡大・縮小の挙動、直接町名リンク、クイズ、全画面の処理は変えない。正式C版、既存比較版、共通エンジンは不変更。

## 判定基準

C版対V32の3画面×32状態の位置差をV25/V28/V30と比較。地域26か所・全域復帰時の位置差中央値が約7〜8pxから明確に改善し、読みONの成果（WebKit390 町名1.652px、読み0.766px）を維持すること。上甲東園の19対18件数違いは別途要修正。321町名のクイズ1・2、15操作状態の回帰試験を行う。位置差の改善が不十分なら正式版採用を見送る。

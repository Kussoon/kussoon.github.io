## 2. 最重要の修正：前回の規則転用ミス

PR #464ではR05の「全国市区町村ラベルを拡大時に重なっても表示」を町名の密集表示にコピーした。しかし規則集のR05本文は**「全国版と全国フォーカス学習（studyPref）」**を対象とし、従来のpref詳細でさえ別扱い。町名レイヤーへの適用は規則から導けない。

従ってこの町名専用の拡大時重なり処理は**既存R05の必須遵守と見なしてはならない**。川西の実機画像は広域時の欠落と拡大時の過密を示しており、**町名用ラベル規則を別の比較試作で決める**必要がある。既存全国マップのR05自体は変更しない。

## 3. R28の現在のコード確認

- `v2/progressive-preview/map-viewport.js` は `wheelArmed=false` から開始し、`onWheel` は許可されていないホイール（ctrlKey例外を除く）を処理しない。地図外ポインター操作で解除するコードも存在する。
- 川西 `town-map-engine.js` はこの `KussoonV2MapViewport.init` を使用しており、**初期ホイールOFFのコード経路は存在**する。
- ただし、5市と完全に同一の初回町域クリック選択・解除・ドラッグ判定が実画面で成立するかは未検証。**コードありと機能合格は別**。

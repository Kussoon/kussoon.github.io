**監査初版：2026-11-16**  
**実装の現在基準**：[`v2/nishinomiya-town-svg-compact-controls-20261116-pilot.html`](../../nishinomiya-town-svg-compact-controls-20261116-pilot.html)（PR #515、**画面・操作ボタンの利用者承認**）  
**品質・機能の正本**：[`NISHINOMIYA_V2_C_BASELINE.md`](NISHINOMIYA_V2_C_BASELINE.md)（PR #470、Leaflet C-BASELINE 1.0）  
**位置づけ**：**仕様統合と残課題の台帳**。この文書を作成しただけでSVG版の全機能を合格・正式採用とみなさない。

## 0. 正本の優先順位と意味

1. **利用者の最新の明示的承認**：2026-11-16 PR #515については、操作ボタンを含む提示画面を「いいですね。OKです。」と確認。これは全321町の全機能回帰に合格したことを意味しない。
2. **動作・地図品質**：C-BASELINE 1.0を維持する。B版から継承した座標補正や複数ラベルを破壊しない。
3. **SVGへの移行と共通化**：実装手段。差異があれば比較し、劣化を正式採用しない。
4. **採用済みの後続UI**：PR #507の細い縦一列操作、PR #515のSVG版への反映、地域五十音順（TOWN-COMMUNITY-ORDER-01）。
5. **将来の他市固有課題**：宝塚市の複数飛び地、尼崎市の「船出」付近の所属や町域接続等は、原典・実地図を検証して本書の共通規則または自治体固有付録へ追記する。**西宮市に存在しない問題を架空のテスト合格として扱わない。**

不採用の共通SVG試作PR #468はPR #469で撤去済み。再利用しない。正式C版、現行トップページ、他市の正式ページは保護する。

## 4. 地域学習（N-REGION）

- `N-REGION-01` 全域＋26コミュニティ。地域名と読みは `COMMUNITY_READINGS` 正本、未確認読みを推測しない。
- `N-REGION-02` **全域を先頭**、残り26件は `Intl.Collator('ja',{usage:'sort',sensitivity:'base',numeric:false})` による読み五十音順。名称で同読みタイブレーク。原データは並べ替えない。
- `N-REGION-03` PCは5列、600px以下は4列。320px/390pxの文字切れ・タップ範囲を検証。
- `N-REGION-04` 地域外の町域とラベルを隠し、対象地域へ表示を合わせる。市全体復帰が可能。
- `N-REGION-05` **岡田山**：1町名として保持。基本「上ヶ原」、広田にも出題。1〜3番は広田、4〜7番は上ヶ原。地域学習中は町全体を紫 `#ad91d4`、未確認の番地境界を描かない。説明文を表示。
- `N-REGION-06` **上甲東園**：1町名として保持。専用TopoJSONにより上ヶ原4丁目相当／甲東2丁目相当を地域選択で切替。架空の境界を補間しない。
- `N-REGION-07` 地域変更時の点滅・クイズの残留を防ぐ。

## 6. サイトの接続とアクセシビリティ（N-LINK / N-A11Y）

- `N-LINK-01` `?town=<町名>` の直接指定と選択後の階層戻りを維持。対象なしは例外停止させない。
- `N-LINK-02` `/v2/geography/`、西宮市トップ、全国V2等の既存公開リンクを不必要に破壊しない。
- `N-LINK-03` 町名検索上限35件は**階層側の仕様**。PR #515の地図そのものには独立検索窓がない。存在しない機能を完成と記載しない。
- `N-A11Y-01` UIの操作名、読みやすさ、ボタン押下可能範囲、`aria-pressed`／`aria-expanded`、キーボードの操作経路とフォーカスを点検。
- `N-A11Y-02` 画面幅320px/390px/PC、ダークモード、拡大文字、iPhone Safariの実機を比較。モバイル模擬検査≠iPhone実機合格。
- `N-A11Y-03` JS構文・DOM・形状データの静的検査だけをもって実表示の合格としない。
- `N-LINK-04` 比較ページは `noindex,nofollow`。正式C版は別ページとして維持。
- `N-LINK-05` 共通フッター／既存サイトのナビゲーションを壊さない。

## 9. 変更管理

1. 改善は必ず **原因→規則ID→新比較URL→自動検査→PC/WebKit→iPhone Safari→画面承認→採用**の順。
2. 一度合格した結果を再利用するなら、依存する処理・データ・CSSのハッシュ／PRを記録し、変更影響がないことを示す。
3. 他市の新たな課題は「共通仕様への追加」と「その市限定の例外」を区別して記録する。西宮市に適用不要な補正を共通コードへ混ぜない。
4. 過去の結果、未採用試作、失敗した方式を履歴として残し、現行正本の要件と混同しない。
5. テストがあることと、現行PR #515に対してそのテストが実行され合格したことは別。実行日時・対象コミット・ブラウザー・出力を記録する。
6. **正式サイト変更・全国共通版の完成宣言はV09合格後のみ**。

# 西宮市321町名を共通SVGエンジンへ接続する移行試作

作成：2026-11-15。関連PR：[#468](https://github.com/Kussoon/kussoon.github.io/pull/468)。**正式版の置換を承認したものではない。**

## 背景と目的

- 全国市区町村V2の操作・検索・ラベル・ズーム・回帰テストの仕組みを町名へ下ろす。
- 西宮B/C版（Leaflet）の成果、特に321町名の事前統合・読み・町域の選択・0.5秒点滅・26コミュニティ・2種クイズを放棄せず、共通SVG版の必要な契約へ整理する。
- 既存5市すべてを同じ「データと設定で追加可能な町名エンジン」に集約する。描画技術の共通化自体を目的化せず、表示品質を退化させない。

## PR #468 の実装範囲

- 既存の `v2/data/nishinomiya-town-v2-premerged.topojson` の321ジオメトリを**内容を変えず** `v2/data/town-maps/28204.json` の `topo` として登録。
- B版 `READINGS` の全321件を `kana.entries` へ対応。**旧B版由来の読み継承**であり、読み出典を改めて公的原票と照合したものではない。
- 比較入口 `v2/town-map/nishinomiya-comparison/` と共通エンジンURL `/v2/town-map/?code=28204` を追加。既存のLeaflet B/C、現行西宮市トップ、全国版・5市階層は不変。
- データ一致・321地名の読み対応・TopoJSON絶対座標のデコード検査、およびChromium/WebKitによる321町域・検索・読み・拡大操作の自動テストを追加。
- 今回の結果は**321データが共通エンジンで使用可能**という先行確認。元B/Cとの画面単位の完全な品質同等性ではない。

## 正式移行判定の不足条件

1. 町名の全域分布・密集・拡大後の文字位置をB/Cと同条件で比較。画面に載っていれば十分という判定にしない。
2. 事前統合の321地名、特殊形状、飛び地、多地点ラベル（`塩瀬町名塩`、`山口町上山口` 等）、B版手動調整の根拠を確認し、**個別手動値のコピーに頼らない自動アルゴリズム**を設計。
3. 同一町名の再選択で0.5秒点滅が止まる契約、空白タップ、選択保持、町域の検索フォーカス、R28ホイールB案を回帰テストへ追加。
4. 西宮C版の26コミュニティ、クイズ1/2、途中終了、復習等は別アダプターとして継承を検討。全部を川西市へ強制しない。
5. WebKit/Chromiumの幅別テストに加え、iPhone Safari**実機**で閲覧・ピンチ・ドラッグ・ラベル・速度を確認。
6. 旧西宮市の公開URL・町名索引・321町名・既存地域トップを維持し、移行時のリンク切れをゼロにする。
7. 旧B/Cとの表示・操作の差を一覧にし、未達があれば既存版を正式採用として維持。

## 合格の基準

**同じ共通形式で表示できること（機械合格）と、既存B/C版の成果を継承したこと（機能・視覚合格）は別。** 前者はPR #468の検査で確認。後者は今後の比較・改善と利用者承認が必要。西宮市で共通化が実証できれば川西市、三田市、猪名川町への標準適用を検討する。

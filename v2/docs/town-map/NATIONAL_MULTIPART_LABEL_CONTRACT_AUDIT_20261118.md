# 全国町名マップ｜複数区域ラベル座標・文字計測共通契約：独立検証

規範：TOWNMAP-SSOT-001（R-TOWN-00、01、02、04、05、06、11、13、14、40、44）。

## 目的
全国統一仕様に基づき、西宮市で承認済みのラベル位置と、宝塚市で採用を目指しているSVG各分離区域からの自動候補生成を、一つのデータ形式で表現する。「飛び地がある自治体」に対する専用コードは作らない。

## 現状確認と継承
- 西宮V34の `town-svg-labels.js` は明示的な `MULTI_LABELS` / `EXTRA_LABELS` / `LABEL_OFFSETS` を使用。塩瀬町名塩2候補、山口町上山口2候補、山口町下山口は追加候補1件を持つ。
- 宝塚の比較版は `town-svg-auto-labels.js` の幾何学候補と、元SVGの `isPointInFill` による内部点判定を使用。穴を町域と取り違えず、分離区域ごとに候補を残す。幾何学候補は人の居住地を保証しない。
- 西宮V34の文字実寸は `Range` 優先、WebKitに対応する `getBBox` / `getScreenCTM` フォールバック。従来の位置補正・比較基準は維持する。
- #599は文字のSVG生成、#600はラベル表示判定を共通化済み。これらの作業は重複させない。

## このPRで追加するもの
- `town-svg-multipart-label-contract.js`：自治体名に依存しない `fromApproved`（確定座標）と `fromSvg`（分離区域候補）の共通レコード生成、および文字実寸計測ユーティリティ `glyphScreenRect`。
- 採用済み西宮市の明示座標の同値性、SVG形式の複数区域入力、候補キー重複検査、文字実寸の測定順序をチェックする独立単体テストとCI。

## 未完了・採否条件
**このPRでは正式ページと既存比較ページの呼出元は変更しない。** 共通モジュールの追加のみで、ラベル表示の同値性が確認されたことにはならない。宝塚の125町・136候補と西宮321町・324ラベルについて、新旧の座標と候補順序、読みON/OFF、地域切替、ズーム・全画面、文字矩形の3ブラウザー実測一致を別工程で確認する。そのうえで初めて接続を比較試作し、既存規則 R-TOWN-04 の採用順序を守る。

# 全国町名マップ｜表示可否判定の共通化（監査記録）

正式規範は `TOWNMAP-SSOT-001` のみ。対象：R-TOWN-00/01/02/04/05/06/13/14/40/44。

これまでに西宮V34で確定した文字範囲の実寸測定、宝塚PR #496で確定した「重なっても主ラベルを表示する」、宝塚PR #591のラベル表示密度検査、PR #598のデータ入力統一を確認。

`town-svg-label-visibility.js` に全国共通の可視判定を追加。入力は**主／副ラベル区分、現在の相対ズーム、町名が選択中か、文字のDOM矩形、地図枠矩形**。主ラベルを重なりで消さず、副ラベルは既存の拡大基準1.15倍または選択中の場合に表示、候補が地図枠と交差するかで判定。既存市名での分岐は設けない。

西宮V34は初期・拡大時に全ラベルDOMを維持する仕様なので、`clipToViewport:false`とすれば既存の表示モデルにも対応できるよう汎用関数化。ただし西宮側は未接続で、挙動を勝手に変更していない。

宝塚市の独立比較ページで、この可視判定だけを共通関数に置き換える。ラベル候補、SVG描画、文字サイズ、アンカー座標、クイズ処理、ボタンは変更しない。旧・新10状態×PC Chromium1280/WebKit390/WebKit320でDOM/表示状態/文字矩形を照合し、全125町名×2クイズと誤答・途中終了の回帰を行う。

**今後の方針**：共通化のために市別の規範を増やさない。表示密度の方針を全国で一本化する際は、主ラベルの視認性と副ラベルの情報量を両市で評価して唯一のマスター仕様書を改訂する。勝手な挙動変更はしない。

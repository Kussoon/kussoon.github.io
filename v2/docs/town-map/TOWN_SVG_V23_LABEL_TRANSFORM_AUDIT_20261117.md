# 西宮市町名SVG V23：ラベル行と親座標の摂動監査

2026-11-17。正式C版・既存比較版HTMLおよび共通エンジンは一切変更しない。

PR #566では読み行のWebKit独自の相対差（文字8px時−7.5px、125%時−9.5px）が判明した。一方PR #567のWebKit読み行への直接+7.5px補正は、run 44029500817で中央値16.493px（以前12.748px）まで悪化し、不採用とした。

## 調査の目的

単純なy補正がなぜ逆効果になったかを分けて測定する。Chromium 1280px、WebKit 390px/320pxの第21比較版をブラウザー上で読みONにし、「西宮浜」ラベルの町名・読み行を同じ座標系で測定する。tspanのyだけを+8px／−8px変えた場合と、親g.labelを移動した場合の変位を計測し、元のDOMに戻す。

これは**座標の因果関係だけを見る診断**で、表示一致を証明するものでも、8pxを正式補正値とするものでもない。次はC版のHTML DOM Range計測値と組み合わせて、ブラウザに依存しない行レイアウト契約が必要かを判断する。

CI PASSの意味は「測定が実行できた」のみ。正式C版の置換・SVG正式採用には直結しない。

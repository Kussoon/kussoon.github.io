## 4. 監査後の工程と保護措置

1. **P1の表示版数誤記を修正**し、V15の地図内部処理・旧比較版・正式C版を変更しない。最低限の検査を付ける。
2. **C版と最新V15の直接視覚監査**を既存のC/V6比較手法に倣って実施し、差の実測と画面証拠を記録する。画面上の縮尺・重なりが違うものを「一致」とは記載しない。
3. アシスタント側のデータ・クイズ・画面・操作検査を総合判定。必要な修正は別比較版でのみ行う。
4. **ここまで合格した後**に利用者のiPhone SafariとPC実機で最終確認する。本人の承認まで正式C版を置換せず、他市の正式ページも変えない。
5. 他市向け汎用エンジンはP2を別ゲートで修正・検査し、まず小規模・飛び地ありなど対照的な地理データで試す。西宮市の同等性合格は他市の地理品質を保証しない。

**今回の監査はコードの実装変更でも公開版の置換でもない。** この報告を保存しただけでP1/P2が解消したとは扱わない。

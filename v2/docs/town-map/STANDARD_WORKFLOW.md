# Kussoon V2 町名マップ 標準制作手順（草案 v0.2：1自治体完結方式）

初版：2026-11-15／最初の検証対象：川西市（28217）

## 目的・優先順位
**1自治体を追加するとは「公式データ取得→町名地図→行政階層への接続→既存回帰→実機受入」までを完成させること。** 地図を単体で仕上げて後からまとめて階層へつなぐ方式は採らない。新しい市区町村のために地図エンジンを作り直さず、これまで全国V2・既存町名マップで確定した仕様・過去PR・回帰テストを継承する。**完成の判定はコードのテスト合格ではなく、データ検証＋実際の描画＋実機操作＋採用判断のすべてを要する。**

既存の確定仕様規則集と実装・過去PRが衝突する場合は、現在有効な仕様を調査・記録してから判断する。規則IDの対応は必ず実体を確認し、番号だけを根拠にしない。全国V2・既存5市の正式版は、個別の比較試作から無断で変更しない。

## 手順と完了ゲート
| 段階 | 作業 | 必須記録・合格条件 |
|---|---|---|
| 0. 継承監査と基準固定 | ベースコミット、過去PR、規則集、既存5市・西宮B/C、全国V2の元実装を照合 | 機能別の『共通必須／自治体固有／将来段階／意図的非採用』と参照SHA・適用根拠を確定。完了前は機能実装禁止 |
| 1. 出典確認 | 公式名称、読み、CODH/e-Stat境界、基準年、ライセンスを取得 | 資料URL、取得日、年月日、正式境界との差分可能性 |
| 2. 元データ監査 | 属性・ID・区画数・座標・リング・重複・欠損・飛び地 | 統計ポリゴンと表示名を**別々に**集計。自動検査報告 |
| 3. 正規化 | 区域IDと名称の多対一対応、丁目、大字小字、読みの照合 | 未確認読みは未確認のまま。区をまたぐ同名は別ID |
| 4. 共通接続 | 自治体別JSONを共通ページに接続 | エンジン・操作コードの自治体別複製を原則禁止 |
| 5. 機械検証 | デコード、地図bbox、ラベルID対応、契約・回帰テスト | 正常系だけでなく、transform有/無、Polygon/MultiPolygon、異常形状も検査 |
| 6. ブラウザ検証 | 全体図・検索・町名フォーカス・拡大画面を視覚確認 | 320/390px、PC幅。**スクリーンショットと実表示の証拠**を残す |
| 7. 実機受入 | iPhone Safariなどで選択・ズーム・ドラッグ・ピンチ・ラベル確認 | 利用者の確認結果、未解決事項、合否記録 |
| 8. 行政階層接続 | `世界→日本→都道府県→自治体→町名` の正本データに1自治体を追加し、検索から地図へ移動・元へ戻る | 既存自治体の件数・階層・リンクを保持。追加後のノード数、町名索引数、遷移、戻る、URLを検査 |
| 9. 正式採用 | 地図と行政階層を**一組**として、URL・既存トップ導線・noindex変更可否を判断 | 採用の明示的承認、変更箇所、ロールバック方法。地図単体の完成は正式完了としない |

## 参照すべき既存成果と適用範囲
- `v2/docs/geography-five-city-standard.md`：PR #445・#448。既存5市721町名の**行政階層・町名一覧・地図への接続**に関する現行正本。5市地図描画エンジンの統一を意味しない。
- `v2/nishinomiya-town-comparison-b.html`（#436）と `v2/nishinomiya-town-study-c.html`（#437）：西宮市の町域・ラベル・点滅・地域学習・クイズの継承候補。これらの実装は全国V2のラベル処理とは別である。
- `Kussoon/nishinomiya`・`takarazuka`・`amagasaki`・`itami`・`ashiya` の各現行 `town-search.html`：異なるデータ・表示形態・例外を持つ。無条件で一つの実装に置き換えない。
- PR #465 の `v2/docs/town-map/LEGACY_INHERITANCE_AUDIT_20261115.md`：第1次継承監査（Draft）。**未完了の監査を完了と見なさない**。
- `MAINTENANCE_RULES.md` の現行正本所在地と各規則IDは、実ファイル確認まで未確定。適用根拠のない『全国ルール』を町名マップに強制しない。

## 実装上の原則
- データ：`v2/data/town-maps/<自治体コード>.json`
- 比較ページ：`/v2/town-map/?code=<自治体コード>`（比較試作中は `noindex,follow`）
- 既存の共有部品：`v2/common/js/label-engine.js`、`readable-labels.js`、`town-map-engine.js`、`v2/progressive-preview/map-viewport.js`
- 共通エンジンが利用する入力契約を確認し、必要なら**共通アダプターのテストを追加**する。
- 動作不良時、町名ごと・自治体ごとの応急補正より、原因と共通修正を優先する。
- データ、テスト、作業記録は変更と同時に更新する。

## 失敗を再利用できる知識へ
不具合には「再現手順→現象→根本原因→変更ファイル→再発防止テスト→ブラウザ再検証→採否」を残す。2026-11-15川西市の transform のないTopoJSONをデルタ加算した不具合を、典型的な失敗例として扱う（詳細は cases/28217-kawanishi.md）。

## 次の自治体への適用
順序は **既存5市→川西市（6番目）→三田市（7番目）→川辺郡猪名川町（7市1町）→神戸市9区**。各自治体を、地図だけでなく既存 `v2/geography/` の行政階層につないでから次へ進む。町名数は統計表示候補と公式学習索引の基準を照合し、未確定の暫定合計を確定値として記録しない。

川西市を基準例として、その後の三田市（28219）・川辺郡猪名川町（28301）・神戸市（28100・9区）では「データ・設定だけでの接続」を目指す。これが成立しない場合は例外を記録し、**一般化できる変更と自治体固有情報を区別**する。

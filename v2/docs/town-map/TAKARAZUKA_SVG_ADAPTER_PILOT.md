# Kussoon V2｜町名SVG共通エンジンの他市展開・第1検証（宝塚市）

作成：2026-11-15 21:40:23 JST

## 対象
西宮市以外の実際の町域データを使った最初の比較検証。
- 元ソース：`Kussoon/takarazuka` の `town-search.html`（SVG viewBox 1000×1700、125町域）と `data/takarazuka-town-info.json`（125町名・確認済み読み）
- 比較試作：`/v2/takarazuka-town-svg-adapter-pilot.html`（未採用）
- 新規共通アダプター：`v2/common/js/town-svg-source-adapter.js`

## 新規アダプターの役割
元宝塚市サイトに埋め込まれたSVG `path.town[data-name]` と公式サイトが使用する同じ町名台帳を、同一オリジンで読み込む。125件の数、町名の重複、読みの有無、町域と町名の完全対応、パス定義の有無を検査してから表示。SVGの`d`を再計算・間引きせず直接再利用する。

地図の拡大・縮小は第2・第3段階の共通処理 `town-svg-viewport.js`, `town-svg-core.js` を利用。既存の宝塚市SVG図形を扱うので、投影座標変換や形状修正はしない。

## 今回できる操作
125町域の一括描画、町域タップで黄色点滅（0.5秒）、町名・読み検索（最大35件）、町名直リンク `?town=`、市全体表示、＋/−、ドラッグ・ピンチ。

## 未完成・未採用の理由
- 125件の町名ラベルを自動で配置していない。元の検索ページに町名ラベルは存在せず、西宮市C版相当の位置・読みやすさを裏付ける配置データがない。安易なバウンディングボックス中央への一括配置はユーザー承認前に行わない。
- 宝塚市20まちづくり協議会の所属データは存在するが、五十音順地域選択に必要な**確認済み地域名読み**をまだ採録していない。未確認読みを推測して並べない（TOWN-COMMUNITY-ORDER-01）。
- クイズ1・2は未実装。元ページのクイズや正式地図を置き換えない。
- 元データの変更がこの試作へ即時反映される依存関係がある。正式化時はバージョン固定等を検討する。

## 回帰・次の段階
Chromium 1280px、WebKit 390/320pxで125パスとユニーク町名、検索、直リンク、ズーム・リセット、JSエラーを検査。実機iPhone Safariの比較は別途。
次はユーザーの表示確認後、ラベル位置・サイズ仕様を全国へ再利用可能な形式で整える。既存の西宮市C版・宝塚市元サイトには手を加えない。

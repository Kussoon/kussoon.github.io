## 第4段階｜最終自動監査→利用者実機受入：**未合格・保留**

PR [#553](https://github.com/Kussoon/kussoon.github.io/pull/553) で、C版対V16の初期・読みON・125%・26地域・全域復帰・代表2町の直リンク、計32状態×3環境を比較。

**追加で判明した残件**：

1. 読みON・125%では、初期表示で一致しても大きな位置差が再発。V17・V18比較で縮小しているがゼロではない。
2. 全26地域切替時には、C版のTooltip要素が地域外でも多数DOMに残る一方、SVG側は対象地域へ絞る。C版で実際に視認されるラベルと非表示要素を区別し、正本の「対象地域のみ表示」という仕様に沿って判定する。単にC版DOMを複製しない。
3. 地域全体表示・市全体復帰・町名直リンクでC版とSVG版の中心・ズームが異なる状態がある。全域初期だけ合格として正式採用しない。
4. 同一画面の実画像比較と、ユーザーによるiPhone Safari/PC実機のタッチ・文字視認性評価は、最終ゲートとして未実施。
5. 別全国CIの`v2/tests/kawanishi-town-map-contract.test.cjs` 欠落による失敗は依然として独立残件。試験を削除して合格を装わない。

**次回の作業判断**：まずV18の最新コミットと専用CIの状態を再確認。次に読みON・125%・地域切替・全域復帰・直リンクの差を個別に原因分解し、既存版の保持を条件に比較修正する。自動監査とアシスタントによる画面検証で問題なしと判定するまで、利用者実機検査へ進まない。ユーザーの明示的承認なしに正式C版も他市も置換しない。

※ 数値比較はブラウザー上のSVG文字枠／Leaflet Tooltip矩形中心の位置差。これだけで文字の視認性や操作感を証明しない。

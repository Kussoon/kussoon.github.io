# 西宮市SVG V25：DOM Rangeによる文字行アンカー位置の比較試作

2026-11-17。正式Leaflet C版・既存V20/V21/V22比較版と共通レンダラーは不変。

## 根拠

PR #568の摂動監査でWebKitのSVG tspan.getBBoxが複数行の親text全体を指し、行毎の位置計測に使えない例が確定。PR #569のDOM Range監査run 44034529000はPASSし、読みON時WebKit 390pxで町名差中央値9.092px、読み差7.941px、行間相対差1.16px。320pxで町名8.521px、読み7.363pxであり、問題の大半は読み仮名行単独ではなく**名前文字アンカー全体の配置**にある。

## 変更

第21版HTMLを独立コピー。 `townTspanScreenRect`で、tspanの文字内容を対象に `Range.selectNodeContents(el).getBoundingClientRect()` を優先し、値がない場合に限り従来getBBox/ScreenCTMへフォールバック。C版での実文字基準と同じ方法を使用する。

WebKit専用User-Agent分岐や固定の補正ピクセル数は一切使わない。表示内容、クイズ、地図領域、描画データ、ボタン、リポジトリ共通エンジンは変更しない。

## 受入条件

3ブラウザサイズ、32状態のC版比較。読みON・文字125%・地域26・市全体復帰・直接町名リンクの差をV21と比較し、全体および読み仮名が確実に改善し、未変更状態での回帰がないこと。別途クイズ1・2各321問、UI状態テスト。CIが成功しても、実表示の差が十分小さい場合にだけ次の実機確認段階へ進める。

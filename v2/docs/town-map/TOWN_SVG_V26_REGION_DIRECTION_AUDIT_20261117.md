# 西宮市SVG V26：地域切替・復帰時の方向別ずれ監査

基準：Leaflet C（不変更）と、読みONの大幅な改善が検証されたSVG V25（PR #570 / run 44037967035）。

V25の残余問題：地域選択時に約6〜9pxの文字位置差、市全体復帰後約7〜8pxの位置差。上ヶ原の上甲東園は大きな異常値。全画面・ラベル・クイズを改変する前に、ブラウザー・地域・町名ごとに、左右(dx)・上下(dy)・文字幅・表示件数・Cとの差の方向性を検査する。

## 検査

PR #566の方向別計測スクリプトを元に、SVGの計測をV24/V25で確立した実文字Rangeへ変更し、対象URLをV25に固定assert。Chromium 1280 / WebKit 390・320で、初期、読みON、文字125%、全26地域、全域復帰、町名直接リンクを対象にする。中央値/95パーセンタイル/最大、各方向の中央値、最悪の10件および町名の表示数をJSONへ記録。

この検査がPASSでも表示一致にはならない。表示差の符号と地域の偏り、町名重複への影響を分析してから、次の独立試作で根本修正案を検証する。共通エンジン、Leaflet C、V25の表示コードは変更しない。

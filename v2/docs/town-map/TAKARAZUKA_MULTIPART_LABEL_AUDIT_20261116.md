# 宝塚市町名SVG｜複数輪郭・ラベル候補点の初回監査

調査日：2026-11-16。対象は `Kussoon/takarazuka/town-search.html` に収録された125個の `path.town[data-name]`。
本書は比較試作用の暫定調査であり、公式住所境界・市街地人口・住宅地分布を検証したものではない。

## 調査手順
各町の SVG `d` を `M` コマンドで分割し、`L` 座標列を閉じた輪郭として符号付き面積（靴紐公式）を計算。絶対面積10 SVG平方単位以上を暫定的な主要輪郭として抽出した。**SVGの `M` の数は飛び地の個数ではない。** 微小な線や穴を含み、面積の符号・包含関係を照合する必要がある。

## 飛び地と誤認してはいけない代表例
**長谷**：3サブパスのうち主要なものは外周 `+29,393`、内側の `−834`、`−18`。負面積2輪郭は `芝辻新田` の `+834` と `+18` に相当する内側の穴であり、長谷の独立した3区域と数えてはいけない。計算上は「複数輪郭」だが「複数の飛び地」ではない。

## 位置基準の設計
- 地図の町名ID、選択、黄色点滅、クイズ1・2は**町単位のまま**。複数ラベルはその町の複数地点表示にすぎない。
- 地図初期表示では衝突を減らす。拡大時には候補ラベルを段階的に増やす。
- 広い山の中心へ自動的に置くのではなく、市街地寄りの小さな区画も候補として提示する。
- 「住宅地」「市街地」の優先順位の根拠となる人口・建物・土地利用データは未導入。**面積の大小から市街地と断定しない**。最終位置は比較画面を実機で確認して承認する。
- 現行の `v2/takarazuka-town-svg-c-layout-pilot.html` と西宮市のC基準版は変更しない。

## 追加検証が必要な事項
ラベル候補の点が元SVGの塗り内に存在すること、複数パーツのタップ・点滅が一体で動くこと、密集市街地と山間部での表示、iPhone Safari、320/390pxとPC幅の回帰、クイズの解答および終了後の再表示。

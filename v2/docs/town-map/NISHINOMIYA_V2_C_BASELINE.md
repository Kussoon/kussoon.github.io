## 1. 最重要の合意

利用者は2026年11月15日、11月14日の**V2 C版そのもの**を町名マップの基本形として採用し、ラベル表示を変更せず引き継ぐよう指定した。これを確定仕様とする。

- **B版の地図・ラベルの配置、サイズ調整、見た目を引き継いだC版を基準とする。** B版のラベルを独自の配置アルゴリズムで置き換えてはならない。
- **C版の26コミュニティ選択とクイズ1・2を含めて**基準とする。ラベルだけのB版へ仕様を巻き戻さない。
- 「共通エンジン化」「SVG化」「全国V2の内部処理への統合」は**実装手段**であり、利用者に承認されたC版の表示・操作を退化させる正当な理由にならない。
- [#468](https://github.com/Kussoon/kussoon.github.io/pull/468)の「新・共通SVG版」は表示品質が不合格のため**不採用**。[#469](https://github.com/Kussoon/kussoon.github.io/pull/469)で撤去済み。**再利用する際もC版との視覚・操作比較が先**。
- 既存C版のHTML/JS/ラベル配置データは正本として保持。改修が必要な場合、まず別URLの比較試作・自動回帰・iPhone Safari実機比較を実施し、明示的な採用判断後に変更する。

## 3. 地図とラベルの確定仕様（原則不変）

### 3.1 ラベル表示

- **Leafletの常時表示Tooltip**（`permanent:true`、中央寄せ、`interactive:false`）を使う。ラベルを非表示にしたいクイズ中は例外。
- **透明背景、濃紺系文字、白色縁取り**（`-webkit-text-stroke:.18em #fff`）、太字、中央寄せ。背景色の付いた札状ラベルに変更しない。
- 元のB版にある町名ごとの**`LABEL_OFFSETS`**を維持する。これは実装上の確定した微調整であり、機械変換の際に消してはならない。
- **`MULTI_LABELS`**で複数地点に同じ名称を表示（例：塩瀬町名塩、山口町上山口）。
- **`EXTRA_LABELS`**で追加地点のラベルを表示（例：山口町下山口）。
- 文字サイズ：CSS `--town-font` の初期基準**8px**。`initialZoom` からのLeaflet拡大差に基づく倍率 `1.18 ** (zoom-initialZoom)` を **0.75〜2** の範囲に抑え、さらに手動の `fontPct/100` を乗じる。表示式は実装の `fontScale()` に従う。文字＋／−は**25%刻み**、手動指定は**75〜200%**、リセットは100%。
- 読み仮名：初期**OFF**、ボタンでON/OFF。ON時は町名の下段に `small.reading` を表示し、字体は本文の**0.78倍**。未確認の読みを推測して追加しない。
- ラベルは町域レイヤーを切り替えてもC版既存の配置規則を継承する。自動衝突判定を新しく導入し、既存のラベルを隠したり、代表点を入れ替えたりする変更は別途比較・承認が必要。

### 3.2 地図・選択操作

- 通常町域：青色塗り `#76b7db`、白い境界線、塗り不透明度0.82。選択は黄 `#ffd14c`、**0.5秒間隔**で通常色と切り替える。
- 選択した町を**再タップ**すると点滅を停止。別の町を選択すると前選択を解除して新規選択する。
- 検索または `?town=` から町を選ぶと、対象区域へフォーカス（`fitBounds`、`maxZoom:15`、余白50px）。通常の地図タップ選択では不要な再ズームをしない。
- ＋／−、**市の全体／区域全体**、全画面／戻る、文字サイズ＋／−／100%、よみがな切替を維持。地図本体はパン、ピンチ等に対応。
- 地図ホイールは初期無効。地図内クリックで有効化、地図外のポインター操作で無効化する（町名検索版のホイールB案）。`zoomControl:false`、`scrollWheelZoom:false`で生成。
- 全画面は `100dvh` と `map.invalidateSize()` で再計算する。
- 右下の地図操作群と右上の全画面ボタン、地図の上のクイズ回答テキストの既定配置を維持。

## 4. 26コミュニティ学習

- 「西宮市全域（321町名）」または**26コミュニティ**を選択。地域名には確認済みのよみを表示。
- PC幅は地域選択のボタンを基本5列、**600px以下では4列**とする。名称と読みが操作可能なサイズで表示される。
- 地域外の町域とそのラベルを地図レイヤーから外し、選択地域の地図範囲に合わせる。地域選択を解除すると市全体へ戻る。
- **岡田山**：通常の代表所属は「上ヶ原」。地域学習では「広田」でも対象。広田の1〜3番、上ヶ原の4〜7番という帰属説明を表示。町全体を紫色で表示し、番地ごとの精密な境界線を装わない。
- **上甲東園**：「上ヶ原」側4丁目相当の構成、「甲東」側2丁目相当の構成を専用TopoJSONから切り分けて地域選択に使用。町名そのものは同じ「上甲東園」として扱う。
- クイズのモード中は町名Tooltipと読み仮名切替ボタンを隠す。通常モードに戻したら復帰する。

## 5. クイズ仕様

### クイズ1「町名→場所」
- 問題文：「○○（読み）」の場所を地図で選ぶ。**名前を隠した町域**から回答する。
- 間違った町域を押すと減点し、誤答場所を赤色で表示。地図上に「違います。そこは『○○（読み）』です。」と表示。同じ誤答場所を同一問で再タップしても重複減点しない。
- 正解で黄色く表示し、回答テキストに「正解です！」、次の問題へ移動できる。答えを見る操作も維持。

### クイズ2「点滅→4択」
- 正解の町域を黄色く点滅（**0.5秒間隔**）。町名・読みの**4つの選択肢**から回答。
- 誤選択肢は赤くし、減点してそのボタンを無効化。他の選択肢で回答を続行できる。
- 選択肢の紛らわしさを考慮し、共有アーク由来の**隣接町域を優先**、同じコミュニティの町名や近距離の町名を次の候補とする（C版 `choiceCandidates()` が正本）。

### 共通する進行
- 全市または選択地域の町名を出題対象とし、出題順はシャッフル。1問ごとに得点と進捗を表示。
- 満点未達時は「間違えた問題をもう一度」／「最初からもう一度」／「地域選択に戻る」。途中終了は「ここでやめる」。
- クイズ中は町名ラベルを隠すが、通常地図のラベル規則を**変更するわけではない**。

## 6. 他市への共通化――守るものと変えるもの

| 区分 | 全国へ適用するときの扱い |
|---|---|
| **絶対に継承する基本仕様** | C版のラベル見た目・配置品質、操作、読み切替、検索／選択、点滅、地域選択とクイズ1/2、戻る・実機可読性 |
| **自治体ごとに差し替えるデータ** | 自治体名・コード、町域TopoJSON、町名・読み、地域区分／読み、町名の所属、特殊境界、URL・出典 |
| **自治体固有として保持する例外** | 西宮市の岡田山・上甲東園、複数地点ラベル等。全市に同じ例外があると仮定しない |
| **共通エンジン化の検討対象** | JavaScript/CSSの重複整理、位置データの外部設定化、地図ライブラリの選択、描画パフォーマンス |
| **採用禁止の進め方** | 既存ラベルを再計算で置換し、見た目が劣化しても「エンジン共通化に成功」として正式採用すること |

SVG実装がC版のラベル位置・白縁・文字幅・倍率・複数配置・操作・速度を再現するならSVGを採用してよい。しかし、**SVGであることを優先してC版を壊さない**。共通化の目的は「同じ実装方式」であり、利用者にとっての品質はこの基準より下げない。

## 7. 変更管理・検査・完成ゲート

1. 既存のC版とB版、全国V2、町名検索ページの**差分と適用範囲**を先に記録する。
2. コード修正は**比較試作URLとブランチ**で行い、C版の確定実装を無断で上書きしない。
3. 画面幅**320・390pxおよびPC**、iPhone Safari実機で、市全体／密集地／飛び地／読みON/OFF／文字±／選択点滅／クイズ両モード／全画面を検証。
4. **321町名、26コミュニティ、地形データ、ラベル特例、岡田山・上甲東園、階層の`?town=`リンクと戻る導線**を回帰テストに含める。
5. 既存B/Cとの比較画像を同じ画面幅・ズーム・地図領域で保存。差異を仕様に整理し、ユーザーの明示的承認を得るまで正式採用しない。
6. PRには変更対象、確定規則ID、旧版との違い、成功したテストと未確認項目を明示する。
7. **「動く」「CIが通る」は十分条件ではない。** 文字が読みやすく、前のC版と遜色ないことが必要。

## 注意事項
1. **125町名ラベルは仮配置**。現在はパス形状のバウンディングボックス中心または近傍の内部点から求める簡易計算であり、正式C版で承認済みのラベル位置・オフセット品質と同等ではない。町域の手動オフセットは未移植。
2. **20地域の読みを推測しない**。町名台帳に同名の町があるときだけ、その町名の読みを流用。未確認の地域名には「読み確認中」を表示する。全地域で読みがそろうまで TOWN-COMMUNITY-ORDER-01 の五十音順に並べ替えず、元の名簿順を維持する。
3. クイズ2の誤答候補は仮の近接度計算（表示パスの矩形中心に基づく）を使用。正式仕様の境界隣接判定は移植していない。
4. クイズ1/2・全域/区域・中断時点滅・全問結果を設けるが、画面と操作の比較段階。既存ページと置き換える判断ではない。
5. 元SVG町域の修正をこの試作から行わない。SVGパス・町名数・読みと20地域所属を共通アダプターで検査する。

# 全国町名マップ｜ラベルSVG要素生成の共通化監査（履歴資料）

規範：TOWNMAP-SSOT-001 R-TOWN-00、01、02、04、05、06、14、20、40、44。

西宮市V34で利用中の `KussoonTownSvgLabels.render` は町名＋読みのtspanを生成する。宝塚市PR #598の採用済み比較版では、同じDOM生成処理を宝塚専用JSの `drawLabels()` 内に持っていた。

今回、全国共通`town-svg-labels.js`の`render`へ**任意の`options.key`と`options.reading`を追加**。省略時の従来`d.id`と`readings[d.name]`という西宮市の動作は厳密に保つ。宝塚側では独立比較版からこの共通関数を呼び、SVGの`g.label/text/tspan`を同じモジュールに生成させる。**自治体名で分岐するコード、自治体固有の別規則、特別なCSSは追加しない。**

ただし、位置計算と表示密度の統合は別段階：宝塚の幾何学候補136件と主ラベル優先、西宮V34の文字ノードRange実寸・アンカー補正には既存の採用差がある。これを強引に一度に置換すると以前の改善を失うため、まず文字DOM生成だけ完全共通化し、その後同じラベル座標契約を設計する。

## 合否基準

- 宝塚既存版との10状態（全市初期・読みON・文字拡大・ズーム・読みOFF・全体へ復帰・仁川・西谷・全市・全画面）で、全てのラベルについて**name、reading、key、anchor、候補優先、SVG要素構造、表示状態、transformを完全一致**。
- 文字矩形についてブラウザー差・同時表示の描画タイミングを考慮し**2px以内**。町域125件とメニュー21件完全一致。PC Chromium1280、WebKit390、WebKit320。
- 共通関数の既定引数が西宮版と同一DOMを生成することを単体検査。よみがなON/OFF、複数地点の別keyを確認。
- クイズ1・2各125問、誤答・中断・復習、20地域の検査を3画面すべてで実施。
- 正式宝塚市・西宮市の元ページは不変。採否に先立つ独立比較。

今回の資料は別仕様書ではなく、唯一の正式仕様書への適合を判断するための監査履歴。

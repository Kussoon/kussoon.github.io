# 西宮市SVG V22：WebKit読み仮名行位置の独立比較（2026-11-17）

前段の方向別監査PR #566（Run 44028972830、PASS）では、WebKitで読みONにしたとき、C版に対して読み仮名のYが約−12.7px（390px）・−12.2px（320px）、町名Yが約−5.2px・−4.7px。両者の相対差は**−7.5px**、文字125%では**−9.5px**と判明した。

## 実験内容

V21をそのまま複製した独立ページで、WebKitの読み仮名行のyにのみ「文字サイズ×7.5/8」を加える。これは**原因仮説を検証する限定的な比較補正**であり、User-Agentの判定と測定値の定数を共通エンジンに採用する提案ではない。町名行・町域・画面基準点・地域・採点・UIは変更しない。

## 判定

Chromium 1280、WebKit 390/320でC版の実文字矩形と比較。WebKitの読みON時、読み行距離中央値が8px未満になることを最低限の実験成功条件とする。Quiz1/2各321問と15段階の状態遷移も再検査する。

「読み行の相対位置だけが改善した」のと「全画面表示品質がC版に一致した」は区別する。町名行自体の約5px差、地域選択・市全体復帰、上甲東園の別件はなお残る。自動検査成功でも本番採用しない。

正式Leaflet C版・V20・V21ページは変更なし。結果に基づき、次段階でブラウザ種別によらないDOM/SVG行ボックス契約へ一般化できるか検討する。

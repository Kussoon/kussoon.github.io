## 0. 全国共通・唯一の仕様（最上位規則 R-TOWN-00）

**全国すべての市区町村の町名マップに適用する規範は、この一文書だけです。市区町村別の正式仕様書、専用ルール、専用の採点・描画・ボタン処理は作りません。**

全国共通エンジン・本書が定めるもの：SVG描画、地図操作、ボタン、ラベル、読み仮名、ズーム、飛び地・複数パーツ・穴・地域分割の処理方式、検索、クイズ1/2、得点、結果、復習、アクセシビリティ、品質検査。

自治体ごとに与えるもの：町名・読み仮名、町域の形状データ、地域区分・読み、町名と地域の対応、飛び地・穴・分割の形状、承認済み過去比較版の座標、注記。これらは**全国共通の仕様に入力する値**であって、自治体独自の仕様ではありません。

新たな町域形状、所属、操作上の課題が現れたときは、自治体名で分岐する個別コードを増やさず、**全国共通の仕様とエンジンを一度だけ拡張**して、すべての自治体で使えるようにします。従来の改善と比較検証したうえで本書だけを改訂します。

西宮市の321町名・26地域、宝塚市の125町名・20地域、「上甲東園」の地域分割や「切畑」の複数区域は、入力データ・検証事例です。仕様として全国に固定する数値や、専用の表示ルールではありません。

自治体ごとの**データ監査報告・試験結果**は必要ですが、これを「自治体固有の正式仕様書」へ昇格させないでください。

## C. 地図データと表示（規則 R-TOWN-10〜16）

**R-TOWN-10：データ構成。** 西宮市の対象は321町名・26地域。データは次の現在の実装を基準とする。

- `v2/data/nishinomiya-town-v2-premerged.topojson`：町域形状
- `/nishinomiya/data/community-town-map.json`：26地域・町名所属の原データ（サイトの既存公開経路。リポジトリ `kussoon.github.io` のmainには同ファイルを複製していない）
- `v2/data/nishinomiya-uekoto-community.topojson`：地域境界の例外形状
- `v2/common/js/town-svg-*.js`：共通SVG UI・座標/viewport・描画・ラベル・ジェスチャー・クイズの各モジュール
- 西宮市の確定HTMLに含まれる町名読み、地域読み、ラベル手動オフセット、複数地点ラベルの定義。**データの移設・再生成には正本との照合が必要**。

**R-TOWN-11：全国共通の1町名1ラベル。** 通常表示では町域が分離していても**1町名IDにつき表示ラベルは1件**とする。西宮市の新共通版は321町名・321ラベル。**西宮市V34基準版は324件のまま保存**し、過去の受入試験の期待値を書き換えない。歴史的基準の追加3件は`塩瀬町名塩`、`山口町上山口`、`山口町下山口`の各1件。ラベルを1件にする新規則は町域データ・クイズの出題単位・地図タップの正誤には影響させない。

**R-TOWN-12：地域別表示。** 26地域の選択、町名数、地域名の読み（例：上ヶ原〈うえがはら〉・香櫨園〈こうろえん〉）を維持。市全体と地域全体の拡大・リセットは、その範囲を基準に行う。ユーザーの地図操作で選択地域・クイズ状態が意図せず失われないこと。

**R-TOWN-13：飛び地・穴・複雑な形状の全国共通配置。** 1町名に複数の離れた町域があっても、文字を配置する区域は1つだけ選ぶ。**役場・行政機関の所在地や、原図の配列順は優先条件にしない。** 文字全体を収められる区域のうち面積が最大の区域を優先し、外周・穴・凹形状の内部に文字矩形が入るかを検査する。文字全体が収まらない場合は**ラベル中心を必ず町域内**に置き、はみ出しを抑えるフォールバックを使う。文字の多少のはみ出し・ラベル相互の重なりは許容し、手動オフセット調整を全国制作の前提にしない。飛び地のどの区域もタップ可能にする。`上甲東園`の上ヶ原／甲東別の形状、`岡田山`の所属と注記、宝塚市の複数区域と穴は維持し、市別の専用分岐は作らない。複数ラベルは**旧V34の履歴データとしてのみ保存**する。

**R-TOWN-14：ラベル基本と測定。** 読み仮名は初期OFF、ON/OFF切替可能。新共通方式は各町名1個のラベルをSVGに表示し、**文字100％・読みOFFの実文字寸法**を測定して配置先を計算する。文字全体を町域内に収めることは最優先だが、町域が小さく不可能なら中心点の区域内配置を優先する。読みON・文字拡大・表示倍率変更時の全文字内包は要求しない。地域表示等の再配置では、読みOFF時にDOM Rangeで測定した**町名の文字中心をアンカーへ合わせる**という既存の共通文字位置補正を維持する。旧V34の手動座標・調整値・読み位置は基準版に保存し、新方式への自動転記や市別手修正を標準工程にしない。

**R-TOWN-15：色・選択。** 通常の町域は青系、境界は白系、選択・点滅は黄色、誤答などのフィードバックは赤、岡田山の特例は紫系。これらの役割と視認性を維持。地図タップで対象の町を示し、解除方法を保持する。

**R-TOWN-16：比較時の重要な例外。** 旧LeafletのTooltipは地域切替直後に**旧DOMラベルが最大約300ms残る**。2026-11-17監査で確認済み。旧方式との一時的なズレを現SVGの誤りとみなさない。比較するなら有効レイヤーのラベルだけを、切替後**360ms以上**の安定状態で照合する。

## D. 画面・操作（規則 R-TOWN-20〜25）

**R-TOWN-20：レイアウト。** 地図は使用可能な画面幅を使う。**地図内右端の同じ右端位置**に上から「全画面／戻る」→「独立した＋ボタン」→「縦型ズームスライダー」→「独立した−ボタン」→「文字＋／文字−」→「文字100％」→「よみがなON/OFF」を縦一列に置く。＋／−はそれぞれ枠で囲み、個別タップで実際に拡大・縮小できる。スライダーは全画面と文字ボタンの間の空間に収め、全画面時も地図面積を無駄にせず、他のボタンと重ならないこと。独立した「市の全体／区域全体」ボタンは置かない。クイズの選択肢は地図外のクイズ欄に表示し、正誤の地図内テキストは地図左上側の専用領域に表示する。

**R-TOWN-21：地図・文字操作。** 地図の拡大／縮小は**指に追従する縦型スライダーと、独立した＋／−の拡縮ボタン**で操作する。スライダー最上端は最大拡大、最下端は**学習地域の選択も解除した自治体全体表示**とする。地図表示とつまみ位置はピンチ・ホイール・地域変更・全画面とも同期する。iPhone Safariで見えるつまみと透明なネイティブ操作面が食い違わないよう、指の位置はPointer Eventsで直接取得して操作する。レールは**白い内側・薄いグレーの枠線・幅10 CSS px**、つまみは**グレーの幅21×高さ27 CSS px**とする。Safariでスライダー周囲に長押し選択拡大鏡が出ないよう選択・calloutを抑止する。右側操作は右端揃え。文字＋／文字−は独立ボタンとして維持し、**「文字100％」ボタンは文字倍率変更後も表示を変えず、押したときだけ100％へ戻す**。読み仮名ON/OFFを維持。文字倍率は75〜200％を25％刻み。地域UIは「市の全体」ボタンを持たなくても動作すること。

**R-TOWN-22：ジェスチャー。** タッチ・ドラッグ・ダブルクリック拡大、地図内で有効化したあとのホイール拡大、地図外タップでのホイール解除を維持。ページスクロールと競合しないよう現行のジェスチャー共通コードに合わせる。

**R-TOWN-23：全画面。** 地図が画面を占め、右上のボタンで戻れる。全画面の入り切りで選択地域・文字倍率・読み仮名・ラベル配置・クイズ状態の不意な初期化を起こさない。

**R-TOWN-24：情報表示。** 地域名、町名、学習範囲、クイズ進行・点数、結果や案内文を整合した状態で表示。**前のクイズの案内を次のクイズに残さない。** 結果メッセージと地図ラベルは別要素として保持する。

**R-TOWN-25：戻り導線。** 地域選択への復帰、地図の市全体復帰、`?town=`町名直リンク、サイト上位の階層への戻りを維持する。正式公開URLとナビゲーションの切替は別作業。

## E. クイズ1・2（規則 R-TOWN-30〜35）

**R-TOWN-30：学習対象。** 対象自治体の全町名または選択地域を出題する。西宮321町名・宝塚125町名は検査済みの入力件数であり、全国共通ルールの固定値ではない。複数区域でも同じ町名IDで扱い、地域データの推測で勝手に出題数を変更しない。

**R-TOWN-31：クイズ1。** 問題文の町名を見て、地図内の対応区域を押す。正誤、誤答した区域名、答えを見る、次の問題への進行、採点を現行実装どおり保持。 **同一問題の回答中に限り、押し間違えた町域の赤を累積表示する。** 同じ町域への再誤答では二重減点しない。正解すると現在の問題の正解区域を黄色で示す。「次の問題へ」では赤と黄色の地図表示を両方解除し、次問は通常の色から始める。採点と復習に使う間違えた「問題」の履歴はクイズ終了まで別途保持する。クイズ開始・地域変更・通常表示への復帰でも色を初期化する。** PR #659で誤って追加された「赤を次の問題にも引き継ぐ」動作は禁止する。

**R-TOWN-32：クイズ2。** 指定の町域が黄色く点滅し、**4択**から町名を選ぶ。誤答は赤、正答は緑で区別。次の問題へ進むまでの状態、点滅の停止、採点を保持。 黄色の点滅・正解表示は現在の問題に限り、次問への移動で以前の黄色を解除する。4択ボタンの赤・緑は従来どおり当該問題内のみ。

**R-TOWN-33：終了・再挑戦。** 「ここでやめる」、結果画面、間違えた問題をもう一度／最初からもう一度／地域選択に戻るを維持。途中終了した問題の案内・点滅はその結果表示中に限る。新しいクイズを始めると前回の案内文と点滅をクリアする。クイズ中は通常の町名ラベルを非表示にするがデータを破棄しない。 **誤答0件の結果画面では、対象がないため「間違えた問題をもう一度」ボタンを非表示にする。** 誤答がある場合のみ表示・操作可能とする。途中終了と全問終了のいずれにも適用する。

**R-TOWN-34：確認された修正。** 2026-11-17に実機で発見した「クイズ1の中断案内がクイズ2正解後も残る」問題は、PR #586で`startQuiz()`時に案内テキストを新しいクイズへ切替える修正を採用。iPhone Safariで修正を再確認済み。**これを戻す修正は禁止**。

**R-TOWN-35：状態の独立性。** クイズ1／2の切替、途中終了、結果、復習、地域変更、文字倍率、全画面、地図の選択・点滅は互いの残留状態を持ち越さない。状態リセットが必要な箇所はUIメッセージも含める。

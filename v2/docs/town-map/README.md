## 最上位の設計目的

**全国市区町村マップで確立したV2の共通描画・地図操作・検索・読み仮名・回帰防止の知見を、町名という一段細かい地理単位へ拡張する。** 単に川西市の地図を別に制作するのではなく、既存5市で得られた町名固有の実装成果を検証し、全国V2の共通部分と結合する。全国V2の規則は対象スケールを確認して継承し、町名の密集度や形状に適用不能な条件は、比較試作・検査・利用者承認を経て町名用規則にする。正式な全国V2や5市の表示・機能は無断変更しない。

このフォルダを**今後新しい自治体を追加するときの唯一の作業入口**とする。昔のPRに散在していた経緯は「採用すべき現在の規則」「一次根拠」「例外・失敗」「今後の要検証」に分けてここに整理する。過去PRは削除せず、根拠へのリンクとして台帳からたどれるようにする。

> 注意：まだ正式仕様ではなく継承監査中の草案。全国市区町村版や既存5市の確定仕様を変更する権限は持たない。規則が衝突したら既存の現在有効な正本と実装・過去PRを確認する。未監査の機能を「継承済み」と書かない。

## 全市区町村の表示方式を統一する方針（2026-11-15）

- **すべての自治体の町名マップで、同じデータ契約・共通エンジン・操作仕様・回帰テストを採用することを目指す。** 既存のLeaflet版と独立SVG版は、ただちに置き換えず比較基準として保存する。
- 「同じ形式」とはHTML・JS・検索・地図操作・読み・町域選択・データ形式・テスト・階層接続を共通化することで、見た目と既存機能を犠牲にすることではない。自治体ごとの境界、読み、公式名称、特例など**データに属する差分**は許容する。
- **不採用：** PR #468の西宮市321町名共通SVG試作は、実画面でラベル品質が既存B版に及ばず、利用者判断により破棄。PR #469で追加した5ファイルをmainから撤去。既存西宮B/C版を表示品質の基準とする。
- 川西市を基準とするだけでなく、既存西宮市での機能維持を**共通エンジンの適合試験**とする。SVGで同等品質・操作・負荷が実現できない場合は、描画方式も再評価する。

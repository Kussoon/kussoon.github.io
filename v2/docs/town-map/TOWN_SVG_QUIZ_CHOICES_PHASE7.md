# Kussoon 町名SVG｜クイズ2の4択候補選定の共通化（第7段階）

**日付：2026-11-17**

## 変更の目的
西宮市第9比較版の「隣接する町名・同じコミュニティの町名を優先し、近い順に選ぶ」という4択候補生成を、自治体依存を持たない新モジュール `v2/common/js/town-svg-quiz-choices.js` に分離。確定済みC版、SVG第9比較版、他市マップは変更しない。

## 候補の優先順（V9と完全一致を必要とする）
1. 対象町名に直接隣接し、かつ同じ主所属地域に属する町名（近い順）
2. 対象町名に直接隣接するその他の町名（近い順）
3. 表示中の学習範囲内で、同じ主所属地域に属する町名（近い順）
4. 表示中の学習範囲内のその他の町名（近い順）
5. 全町名から未採用の候補（近い順）

一度選んだ町名を重複させず、正解1件と誤答候補3件の4件を候補にする。その後に**従来のシャッフル関数**で並び順を決める。隣接の定義・距離計算・主所属・出題範囲・乱数は引数として受け取り、共通部品には西宮市の地名・計算ライブラリ・地域名を埋め込まない。

## 比較検査と採否
- `scripts/test-town-svg-quiz-choices.cjs`：隣接・同地域・表示範囲・それ以外の優先順位の単体契約
- `scripts/audit-nishinomiya-v10-candidate-parity.cjs`：V9とV10の全321町名×全域／山口／上ヶ原／西宮浜の4範囲、計1,284組を比較。各町名の乱数は固定して両版の候補4件と順番が一致することを確認する。PC Chromium・モバイルWebKitで実行
- `scripts/smoke-nishinomiya-svg-v10-choices-parity.cjs`：V9/V10の町域・ラベルの5状態×3画面幅の完全一致を確認する
- `scripts/audit-nishinomiya-v10-321-quiz-contract.cjs`：全321町名×クイズ1・2をPC ChromiumとモバイルWebKitで再採点する
- `scripts/smoke-nishinomiya-v10-state-matrix.cjs`：全画面・地域変更・途中終了・復習を含む15段階の状態検査

**検査がPASSするまでは採用・統合しない**。単問候補の一致だけでは、利用者の実機操作や表示品質が完成したとは判断しない。

## 今回は対象外の処理
地図のラベル座標、境界線、スクロール／ダブルクリック、候補の読み仮名表示、点滅、得点計算、地域所属、飛び地図形、全画面、自治体別データの内容は今回一切変更しない。

今回のモジュールは**候補を優先順に並べるだけ**の部品。地理的な隣接判定・距離取得・区域別ルールの確定は今後も地図側が担う。

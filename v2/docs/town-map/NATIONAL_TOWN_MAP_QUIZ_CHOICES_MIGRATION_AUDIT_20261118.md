# 全国共通町名マップ｜4択候補選定の統一・差分検証記録

正本：`TOWNMAP-SSOT-001` R-TOWN-00、01、02、04、05、06、30、32、35、42、44。

## 過去の改善と共通化の方針

- 西宮市の採用版 V34 は `KussoonTownSvgQuizChoices.select` を使用。候補の優先順位は「同じ地域に属する隣接町名→隣接町名→同地域の対象範囲→対象範囲→全町名」の順、最終4択の選択肢順はシャッフル。
- 宝塚市は独自の `candidates(target)` に、**同じ優先順**と地域の共通所属判定を重複実装していた。候補距離は宝塚SVG町域bbox中心の二乗距離で算定。西宮側の球面距離と同じ数式に無断変更すると過去の候補を変える可能性がある。
- 今回は全国共通 `town-svg-quiz-choices.js` の`select`に任意の `sameRegion(name,target)` を追加する。省略時は従来の `primaryRegion` の動作をそのまま維持する。**同じ地域に複数所属する場合も、全国共通の一つの選択ロジック**で扱う。市名による分岐や市専用仕様は作らない。
- 宝塚市の新比較HTML `v2/takarazuka-town-svg-national-choices-20261118-pilot.html` は既存の全国共通採点版から分離し、4択候補の選定だけを共有モジュールへ移す。元の比較ページ・元町域・ラベル・ボタンは変更しない。

## 合否条件

1. 宝塚市の125町名×（全域＋20地域）＝**2625組**について、置換前後で4択候補**4件の多重集合・表示順まで完全一致**すること。シャッフルを固定し、地理的優先順を比較する。
2. 西宮市の呼び出し形式（`primaryRegion`のみ）では既存の優先順位を維持する。

4. 正式ページやほかの自治体は変更せず、新しい比較版だけで採否を判断する。

## 他の共通化候補（次の工程）

- **データ読み込み：** 西宮市はTopoJSON＋所属台帳＋例外形状を共通データ契約で読み、宝塚市は旧HTML内SVGから共通SourceAdapterを経由する。データ形式の違いは共通の入力アダプターで吸収し、町域形状や町名IDを書き換えずに変換できるか検討する。
- **ラベル配置：** 西宮市で確定した文字のDOM Range中心位置、宝塚市で検証した複数形状の候補と主ラベル維持を、全国共通の描画・ラベル規則として共存させる。市専用補正や非表示ルールを増やさない。
- **クイズ地理：** 宝塚側の複数輪郭からの隣接判定は市固有ルールではなくSVG入力形式向けの地理アダプター。TopoJSON arc隣接と入力形式の差分を全国共通のデータ変換・契約で扱う。

現時点では全国共通仕様の新しい独立文書を増やさない。この報告は試験結果を記録するための履歴資料であり、規範は唯一のマスター仕様書のみ。

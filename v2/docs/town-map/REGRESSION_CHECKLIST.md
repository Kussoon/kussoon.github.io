# Kussoon V2 町名マップ検証チェックリスト

検査対象（自治体コード・コミットSHA・URL・端末・確認日）を必ず記録する。スクリプトがPASSしても「画面検証PASS」とはしない。

## データ・静的
- [ ] 出典URL・年月日・ライセンス・読み出典記載
- [ ] 統計区画数、表示地名数、同名多区画数を別々に集計
- [ ] 区画IDの一意性、空名、非有限座標、リング閉鎖、bboxを検査
- [ ] transformあり・なしの両方式を検査
- [ ] Polygon・MultiPolygon、複数リング・飛び地を検査
- [ ] 読み仮名照合状況と欠損一覧
- [ ] `noindex,follow` と正式版非変更
- [ ] 全国V2と既存5市の回帰テスト結果

## ブラウザ（表示の証拠を残す）
- [ ] 読み込み時にエラーがなく町域の輪郭が地理的に成立
- [ ] 市全体の地図が枠内に収まり、極端な余白・クリップがない
- [ ] 文字と境界線の視認性が既存V2の確定仕様に合う
- [ ] ラベルの初期状態、重なり・拡大時の出現規則が確定仕様に合う
- [ ] 町名検索（候補最大35件）、同名・丁目の区別
- [ ] `?town=<名称>` の直接表示、検索から選択してフォーカス
- [ ] 選択とタッチドラッグ・ピンチが競合しない
- [ ] 右下ボタン、文字サイズ変更、全体表示
- [ ] 320px・390px・PC幅で横はみ出しや重なりなし
- [ ] iPhone Safari実機で確認し、確認者・実施日・結果を記録

## 合否のルール
- **未実施は未実施**。代理ブラウザのPASSをiPhone実機のPASSと書かない。
- スクリーンショットで描画破綻が確認されたら不合格。コード上の件数合格で上書きしない。
- 表示差異は過去PR・規則集と照合してから修正する。表示を勝手に間引く等の独自規則を足さない。
- 既存正式版への反映は、実機確認と明示的な正式採用判断の後に行う。

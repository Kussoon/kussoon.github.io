## 実行結果・不具合検出（2026-11-18）

[GitHub Actions run 44175573300](https://github.com/Kussoon/kussoon.github.io/actions/runs/44175573300) **監査プログラムPASS**、ただし**アプリの不具合1件を検出**。Chromium1280・WebKit390・WebKit320の3環境で同じ結果。

- クイズ1：初回誤答で得点2→1、同一誤答の再クリックは減点なし、正答後ロック、2問終了1点、誤答だけの復習は1問1点。全件正常。
- 最初からやり直し：選択した全市125問へ復帰する。途中終了・結果も正常。
- クイズ2：初回誤選択で得点2→1、選択済み誤答は無効となり再減点なし、正答後ロック、2問終了1点、誤答だけの復習1問1点。全件正常。
- 仁川地域を選択してクイズ1を始めると、出題数は12件。正常。
- **不具合**：クイズ2を途中終了したのち「地域選択に戻る」で`#status`の旧「中断した問題」を残し、さらに仁川地域へ変更しても残存。3ブラウザーで再現。次のクイズを始めると古い文言は消える（PR #589の改善は維持）。
- **原因**：`finishQuiz(true)`は案内を表示するが`stopQuiz(true)`→`showCommunity()`は`#status`を更新しない。このため地域復帰・切替時の案内のみ残る。クイズ採点・進行とは独立。

次は既存版を保持した独立比較試作で、`showCommunity()`の地域表示の案内を更新し、クイズの途中終了・復帰・地域変更の再発テストと全125問正答テストを実行する。正式ページおよび既存比較版のコードを変更しない。

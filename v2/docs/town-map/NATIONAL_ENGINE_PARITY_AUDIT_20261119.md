## 4. 共通化で守る非交渉条件

1. **唯一の仕様**：`TOWNMAP-SSOT-001` 以外に正式仕様を作らない。新しい自治体名で `if(city===...)` のような分岐を増やさない。
2. **元版を保全**：西宮V34、今回承認された西宮・宝塚の比較版、元の宝塚SVGデータを保存する。比較試作と明示的採用の段階を守る。
3. **表示の同一性**：西宮のC基準のラベル中心誤差、岡田山・上甲東園の分割所属、宝塚の候補136と飛び地、地域別一覧・読み仮名を後退させない。
4. **クイズ**：各市の出題・誤答・中断・正答の表示・点滅、誤答0件時の復習ボタン非表示、クイズ1↔2の状態分離を保持する。
5. **性能**：西宮のイベントごとの再測定を復活させない。宝塚の候補ラベルについても連続ズームのフレーム単位の書換回数を実測する。
6. **公開導線**：本監査や共通化のPRでは `/nishinomiya/`、`/takarazuka/`、全国V2の正式公開入口やURLを切り替えない。

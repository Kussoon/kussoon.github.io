# Kussoon V2 町名マップ｜地域選択ボタンの全国共通表示順

**規則ID:** TOWN-COMMUNITY-ORDER-01  
**制定:** 2026-11-15  
**対象:** 全国へ拡張する町名マップの市区町村内地域・コミュニティ選択UI  
**初回適用:** 西宮市 SVG比較試作（正式C版の保護を優先）

## 決定した規則

1. 「市全域」「区全域」など、対象範囲の**全域**を選ぶボタンは先頭に固定する。
2. それ以外の地域は、**確認済みの地域名の読み仮名**をキーとする日本語五十音順に自動整列する。
3. 比較には `Intl.Collator('ja', {usage:'sort',sensitivity:'base',numeric:false})` を用いる。同一読みに対しては地域名を同じ比較器で比較し、決定的な順番とする。
4. **未確認の読みを推測しない。** 読みがない場合はデータエラーとして検出し、データを補うまでは自動整列しない。
5. 地域名・読み・構成町域・地域選択後の地図形状・クイズの対象範囲は並べ替えで変更しない。ソースデータの登録順を上書きする必要はない。
6. 町名・市区町村名そのもののラベル配置順、全国の都道府県一覧などにはこの規則を**無断適用しない**。対象は町名マップの「地域選択」ボタン。
7. すでに正式採用されたC版のプログラムは基準として残す。比較試作で検証後、別途承認を得て正式版に展開する。

## 西宮市での適用と注意

地域名の確認済み読みは、2026-11-14の西宮市C版の `COMMUNITY_READINGS` に従う。  
全域選択ボタンを先頭とし、26コミュニティをソートする。五十音順は地理的な近接や地域の所属を変更するものではない。  
画面幅600px以下で4列・PCで5列というボタンレイアウトは維持する。

## 検証ゲート

- 26件が重複・欠落なく並ぶこと
- 全域ボタンが常に先頭であること
- 読み仮名のソート結果が非降順であること
- コミュニティの個別所属・例外地域（岡田山、上甲東園）・クイズに影響しないこと
- 320px・390px・PCおよびiPhone Safariの実機で、読みやすさと選択操作を比較すること
- C-BASELINE 1.0の正式C版は明示的承認まで変更しないこと

この規則は、`NISHINOMIYA_V2_C_BASELINE.md` のラベルや操作の確定仕様を置き換えるものではありません。

# 西宮市SVG ラベル位置差：V22 方向別診断（2026-11-17）

正式Leaflet C版、V20/V21版のHTMLには変更を加えない。V21を基準として、同じ比較状態の実文字矩形を測定する診断専用のDraft PR。

## 仮説と切り分け

* V21の集計は町名・読み行のユークリッド距離が中心で、横ずれ・縦ずれと文字サイズ差の区別が不足している。
* SVG tspanの矩形計測変更だけではWebKitの読み行の約12〜13px差を改善しなかった。
* 次の描画補正を選ぶ前に、各状態の町名 glyph、読み glyph の中心座標、幅と高さ、読み行と町名の相対位置の差を確認する。

## 新しい検査

`scripts/audit-nishinomiya-c-v22-directional-glyph.cjs` はChromium 1280、WebKit 390/320で、初期、読みON、125%、全26地域、市全体復帰、直リンク2種を比較する。

C版はDOM Rangeによる町名実文字、SVGはgetBBox/getScreenCTMによる画面矩形を使用。各ラベルのC→SVGの signed Δx/Δy、幅高さ差、読み仮名の独立差、読み－町名の相対位置差を算出し、方向別中央値・絶対差95パーセンタイル・最大差上位10件をArtifactsに保存する。

## 合格条件と保護

このPRのCI PASSは**診断スクリプト完走**のみを意味する。表示一致・実機合格とは異なる。結果の方向性が確定するまでは見た目の係数補正をしない。正式C版・V20・V21比較版・共通エンジン・クイズのコードは変更しない。

原因が方向別に確定した後、別の独立V22表示比較ページで修正を試作し、改めて既存の321町×2問・15段階操作・Chromium/WebKit・実画像比較を行う。

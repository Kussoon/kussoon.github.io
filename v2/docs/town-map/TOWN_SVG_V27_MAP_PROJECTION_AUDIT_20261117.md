# 西宮市町名SVG V27：地図投影差と文字ラベル差の切り分け

2026-11-17。PR #571（run 44039059784）で、地域選択後の町名位置差は上下中心に中央値約6〜9px、全域復帰後は左右−4.7〜−5.3px・上下−5〜−6pxと判明した。上甲東園は例外的にWebKitで15〜19px、Chromiumで44pxの差がある。

ラベルのアンカーだけを補正する前に、**地図本体の投影座標に同じずれがあるか**を確認する。Leaflet CとSVG V25 HTMLの既存ページをPlaywrightの一時挿入フックで測定し、いずれのページのHTMLも変更しない。

共通の4つの町（西宮浜、岡田山、山口町下山口、甲子園口北町）の地理中心座標（C地図の町域から取得）を、Leaflet `latLngToContainerPoint` と SVG `projection + transform` で相互比較。PC Chromium 1280/WebKit 390/320。全市初期、上ヶ原・香櫨園・安井・山口の地域表示、全市復帰でdx/dyを記録する。

4点すべてで同じ移動量なら地図の投影・fit処理が主因。地図投影が一致して文字だけずれるならラベルの再配置・基準点履歴処理が主因。4点間で差があれば拡縮率・投影計算を疑う。この監査のCI PASSは測定実行成功のみを表す。正式C版・比較HTML・共通エンジンのソースは変更しない。

## 計測結果と次工程（2026-11-17）

[Run 44039643179](https://github.com/Kussoon/kussoon.github.io/actions/runs/44039643179) PASS。4つの共通地理座標の変位（SVG－C）は、PC Chromium1280・WebKit390/320で、全市初期／地域（上ヶ原、香櫨園、安井、山口）／全市復帰の**全状態で各軸おおむね±1px以内**。地図本体の投影・fit処理の大きな違いは否定された。

例：
- Chromium1280・安井の4点平均 dx−0.640px、dy−0.699px。全市復帰 dx+0.372px、dy−0.620px。
- WebKit390・香櫨園平均 dx+0.223px、dy−0.403px。全市復帰 dx+0.079px、dy−0.120px。
- WebKit320・上ヶ原平均 dx+0.229px、dy−0.228px。全市復帰 dx−0.118px、dy+0.435px。

**結論**：地域切替後のラベル約6〜9px、全市復帰時の約7〜8pxの差の主因は、地図本体の投影位置ではなく、ラベル配置モードの保持履歴であると推定できる。仮説として、よみがなOFF後に `cLabelMode='centered'` が残る問題を独立比較試作PR #573（V28）で検証する。C版・共通地図エンジンは変更しない。

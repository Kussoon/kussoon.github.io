# Kussoon V2 地域階層｜阪神間5市総合監査記録

実施日：2026-11-14  
監査対象：`/v2/geography/`、`hierarchy.json`、5市の町名元データ・橋渡しページ、地図側の既存検査、GitHub Actions。  
変更の原則：**既存5市の元ページ、全国地図、C/B版、地図形状・ラベル・クイズ・点滅動作は変更しない**。

## 監査で確認したこと

**合計：721町名。** 数値は5市の「既存サイトの学習用町名索引」に準拠。行政上の丁目・字の総数ではない。

## 共通実装の監査結果

- 地域ID・親・子・読み仮名は `hierarchy.json` の8ノードで管理。行政親子と学習用 `groups` を混ぜない。
- 町名選択画面は全5市で共通、最大35件を表示。町名検索結果から各市の既存地図に連携。
- 町名の元データには**3種類のアダプター**（TopoJSON+読み、`town-info-array`、`town-list-json`）、地図へのリンクには**3方式**（C版直接指定、既存ページ`?q=`、iframeブリッジ）。
- 尼崎・伊丹・芦屋の軽量JSONは元HTMLからの派生データ。元側の更新を自動反映する仕組みはまだないため、原本との厳密一致検査が必須。
- 3市のブリッジは、元サイトと**同一オリジン**のiframeが動作条件。ドメインの違うサイトへ移設するときは無条件で再利用できない。
- `/v2/geography/` は `noindex` の試作。既存市サイト・全国地図のURL移転・正式公開を意味しない。
- **問題点として検出した文書の陳腐化：** 当初の `geography-hierarchy-pilot.md` の冒頭には「他4市未接続」など作成当時の説明が残り、現行状態と混同する恐れがある。今回、履歴を削除せず、冒頭に正本へのリンクを追加し、別ファイル `geography-five-city-standard.md` を現在の正本に指定した。

## 今回強化する回帰防止

- 8ノード・5市・721町名と各市の町名数をテストで固定。
- 3種類の地図遷移方式を検査し、将来コードを変更する際の誤削除を検出。
- 既存の原本照合テスト（町名・読み・例外）と、全5市のChromium/WebKitブラウザー往復テストを継続。
- 標準仕様書・旧履歴文書だけを変更した場合もCIを起動するようWorkflow対象に追加。

## 残る課題（今回合格と言ってはいけない項目）

1. iPhone Safari**実機**での、パンくず・検索入力・iframeスクロール・表示切れ。
2. 5市の**全721町を1件ずつ**表示・選択する全件ブラウザー検査（現在は市別の代表例と例外）。
3. 公開本番上の全リンクのHTTP監査と継続監視。CIの元リポジトリ内ファイル存在検証と同義ではない。
4. 軽量派生索引の自動更新、元ソース差異の通知・更新責任の定義。
5. `/atlas/` の正式URL決定、行政コードの採用、他国の行政階層の設計、町名・丁目の長期安定ID。
6. アクセシビリティ専門監査と実機での操作確認。

## 結論

5市の地域階層接続は既存のPR #439〜#444で機能の自動検査を実施しており、本監査では**標準仕様・現行正本・CI契約の明文化**を行う。全国または正式ページへの移行判断は、残課題を解消したうえで別途行う。

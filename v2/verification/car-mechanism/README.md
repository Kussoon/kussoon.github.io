## 目的
Kussoon「運転・モビリティ」用の記事「自動車は、なぜ走るのか？」を、**小学生にも理解できる難易度／大人向けの落ち着いた文体**で制作する。まず一般的なガソリンFF車の「燃える→押す→回る→伝わる→進む」を説明し、図解・アニメーションを統合する。燃料別比較は後回し。

## ユーザーとの確認で確定した仕様
- スマホ画面の縮小図で小さな文字を読ませない。**拡大・全体ボタンと必要な横スクロール**を備える。
- FF車の主要部品とオレンジ色の動力伝達経路は太く、大きく、文字は高コントラストに。
- デファレンシャルは車体を天井方向から見下ろし、**左右の車輪の位置を誤認させず、外輪が速く内輪が遅い**ことを示す。正面から見た左右の円盤が不自然に回る旧版は完成版に採用しない。
- 最終的には**プラモデルの断面のように内部が見える図**を希望。
- 現時点では公開・本番差し替えは未承認。
- `/v2/` は公開サーバー配下なので機密情報を入れず、検証HTMLには `noindex` を付与する。

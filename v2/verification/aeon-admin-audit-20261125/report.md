# 全国4,613店舗の行政区域監査

2026年11月25日実施。入力は[PR #760](https://github.com/Kussoon/kussoon.github.io/pull/760)の全国比較表とVer.1.3.2の台帳。通常掲載4,613店舗すべての現行点とCSIS点、計9,226点を検証した。

## 結果

| 照合 | 現行 | CSIS |
|---|---:|---:|
| 期待する都道府県内 | 4,613 | 4,613 |
| 期待する市区町村・行政区内 | 4,595 | 4,591 |
| 同区域外、境界から100m以内 | 18 | 17 |
| 同区域外、境界から100m超 | 0 | 5 |
| 全国の行政区域ポリゴン外 | 0 | 0 |

全国のポリゴン外に出る点はなく、沖合への明らかな外れは検出されなかった。ポリゴンに含まれる河川・港湾・水面や建物の位置は、この照合だけでは判定できない。100mは目視確認を分ける目安であり、境界付近は敷地の広がりや代表点の定義を確認する。

## 改善候補と個別調査

- 番地・号まで詳しい407店舗、親番・街区まで詳しい729店舗は、全件でCSIS点が期待区域内。候補として維持する。区域照合は位置の採用判断を代替しない。
- 個別調査の優先対象は重複を除き246店舗。A 区域外100m超等5、B 境界付近18、C 前回の番号不一致・CSIS複数候補等11、D 番地・号改善かつ差250m以上164、E 残りのうち差1km以上で改善候補または番地・号一致48。AからEの順に判定した。
- 前回対象外2,811店舗も検証した。そのうち境界付近の18店舗を新たに追加。前回の追加調査対象1,802店舗のうち228店舗が今回の優先対象に残り、1,574店舗は今回の個別調査を見送る。全国4,367店舗は優先対象外。見送りには、細かな照合の改善が将来必要になる場合や共通代表点が含まれる。

### 追加調査を効率化する手順

1. Aの5店舗は、まずCSIS照合住所と台帳の公式原文・基準日住所を比較し、既存の運営会社資料で所在地を確認する。公式資料なしに広域代表点を採用しない。
2. Bは境界・沿岸に店舗敷地がまたがるかを、既存施設資料と地理院地図で確認する。数mの差は地図の作成年や図形の表現も考慮する。Cは別地名・番号の取り違えと表記ゆれを区別する。
3. D・Eは同一運営会社・同一施設ごとにまとめ、公式の店舗・施設住所と既存証跡を再利用する。番地・号の一致と位置の根拠がそろう候補を優先する。親番・街区のみの候補や小差の候補は、分布把握に影響するものから扱う。同一座標は施設共用や住所代表点の可能性を確認し、重複店舗と扱う前にID・屋号・住所を照合する。

## データ、距離、品質検証

- 出典・加工表記「国土数値情報『行政区域データ（N03、2026年1月1日時点）』（国土交通省）を加工して作成」。全国版の市区町村シェープファイル N03-20260101.shp（JGD2011／EPSG:6668、125,130ポリゴン）を使用。境界データのZIP SHA-256 は `1f714fca019e22e6f84012dba420384fc7b49c6ad8bd0a867ab1cfb593a78477`。ダウンロードサイトの公共データ利用規約（PDL1.0）の出典・加工明示と個別条件を参照。成果物は照合結果を収録し、境界データ自体は同梱していない。[N03 2026年版](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html) [国土数値情報利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement.html) [東大CSIS利用条件](https://geocode.csis.u-tokyo.ac.jp/home/csv-admatch/#terms-of-use)
- 期待区域は公式住所に対応する台帳の都道府県・市区町村名と自治体コードを使用。市町村名の省略等がある公式原文についても台帳の行政項目を基準とした。4,613件で名称・コードがN03に一致。政令指定都市は行政区まで照合。境界線上は包含。行政界未定・地物の時点差があり得る。
- 現行WGS84をJGD2011の経緯度に変換。CSISの世界測地系経緯度は本監査の縮尺ではJGD2011との小差を区別せず、入力値を使用。区域外距離は周辺の各該当ポリゴン上の経緯度平面での最近接点からGRS80楕円体の測地距離を計算した概算。内側は0。都道府県・市区町村・全国の距離を別々に記録。
- 入力ID集合、座標と住所原文の不変、両座標9,226件の完備、改善候補407＋729件と前回対象外2,811件、区域外5件の取り出し、都道府県別集計と全国総数、ZIPの展開を検査。Google Mapsからの取得、新規ジオコーディング、Excel正本・公開地図・採用座標の更新は行っていない。

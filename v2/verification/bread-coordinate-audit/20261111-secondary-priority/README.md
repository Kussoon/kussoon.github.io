前回の照合先座標と距離を保存しています。No.142は施設の西口側代表位置と東側売場の違いと判断し、C案として候補座標を空欄にしています。B/Cには修正候補を設定していません。

## 地図画像の出典

`gsi-review/no-*.png`は[国土地理院の地理院タイル（標準地図）](https://maps.gsi.go.jp/development/ichiran.html)をもとに、登録点（赤）・前回照合点（青）と注記を追加した図です。青点は前回の照合先で、採用案と同じとは限りません。特にNo.80は前回の照合先へ変更せず登録点を維持するC案、No.142も西口側の現代表位置を維持するC案です。

タイル更新日は未特定。取得日2026-11-11。建物描画は最新現況を保証せず、敷地境界・入口を確定した資料ではありません。[取得した90タイルのURL](gsi-tile-sources.csv)を記録しています。

公式フロア図・出入口図は原提供者のURLとファイルハッシュを記録し、図面本体をリポジトリへ再配布していません。PDF作成メタデータ、画像ファイル名、本文の発表日は区別します。

比較HTMLは既存比較ページの実装を再利用しています。背景地図は地理院タイルへの接続が必要です。図面のピクセルから推測座標は生成していません。`noindex,nofollow,noarchive`を設定。ブランチ上だけのファイルであり、公開URLへ配置したものではありません。

ブラウザー試験はUIの操作を対象とし、タイル通信を遮断して実行します。公式図・建物形状の調査結果の正しさを自動判定するものではありません。iPhone Safari実機・現地・航空写真・ストリートビューは未検証です。

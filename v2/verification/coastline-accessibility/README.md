# 海岸線・陸地輪郭 比較試作

公開中の地図・クイズのCSSや描画コードを変更せず、既存の2026年版TopoJSONと公開版の `v2/progressive-preview/municipality-renderer.js` を使った比較ページです。

## 調査結果

- `maps/national-municipalities.html` は公開全国地図のHTML内CSS・描画スクリプトを使い、段階描画に `v2/progressive-preview/municipality-renderer.js` を読み込みます。
- 県別クイズは `v2/municipalities/shared/quiz.css` と `quiz-app.js` を共有します。ポリゴンは `stroke:none`、境界はTopoJSON共有アークの独立path、初期色は海 `#eaf3f9`・通常陸地 `#d9dea5`・範囲外 `#cbd7db`・境界白1.2pxです。
- 公開全国図と県別クイズは同じCSS/描画経路ではありません。全国図の県別色、ラベル、操作UIには手を加えません。
- 規則集 `v2/national/MAINTENANCE_RULES.md` のR02（区域ポリゴン塗りと共有境界pathの分離、線の累積描画禁止、選択専用stroke禁止）を維持します。
- 全国図の規則集には共通Topology経路は7県、ほか40県と全国概要は別経路と記録されています。この試作のTopoJSON arc利用数分類は入力TopoJSON単位で検証するものです。単独県データでは県外との接合線も外周候補になり得るため、「外周弧＝海岸線」とは確定しません。

## 比較内容

地域選択で9表示を切り替えます。宮古諸島、沖縄全域、奄美諸島、五島列島、広島・香川の瀬戸内海、東京湾、西宮、北海道です。地図は同じ座標範囲・SVG寸法で並び、ズームとドラッグを同期します。

- 現行：海 `#eaf3f9`、陸地 `#d9dea5`、範囲外 `#cbd7db`、全アーク白1.2px
- 候補A：海 `#d8ebf7`、陸地 `#f2f0dd`、範囲外 `#d5dee2`、区域間共有アーク白1.1px、1区域使用の外周弧は濃色 `#486574` 2.4px
- 候補B：候補Aと同色。区域間共有アークも濃色 `#486574` 1.1px

描画は公開全国図と同じprogressive rendererを使います。ポリゴン個別strokeは使いません。境界アークは「複数区域が利用する弧」と「1区域だけが利用する弧」に分け、候補の2つのレイヤーに同一弧を二重登録しません。線幅は `vector-effect: non-scaling-stroke` で画面上の幅を保ちます。

## コントラスト

WCAG 2.2 SC 1.4.11を目安にした相対輝度コントラスト比です。

| 隣接要素 | コントラスト比 | 評価 |
|---|---:|---|
| 候補濃色輪郭 `#486574` ／海 `#d8ebf7` | 5.06:1 | 3:1以上 |
| 候補濃色輪郭 `#486574` ／陸地 `#f2f0dd` | 5.39:1 | 3:1以上 |
| 海 `#d8ebf7` ／陸地 `#f2f0dd` | 1.07:1 | 面色だけでは不足。境界線を併用 |
| 現行白線 `#ffffff` ／陸地 `#d9dea5` | 1.41:1 | 3:1未満 |
| 現行白線 `#ffffff` ／海 `#eaf3f9` | 1.12:1 | 3:1未満 |

色だけに依存しないよう、地理形状と明確な線の位置で海陸を区別します。候補Aの内部共有境界は白のため3:1に達しません。候補Bは内部境界も濃色にし、境界のコントラストを確保しつつ、線が混雑した市街地・小島で強すぎないか比較します。

## 検証

`node --check` と `node v2/verification/coastline-accessibility/contract.test.cjs` が成功。

契約テストは8県のTopoJSONを読み、各ファイル内に一区域使用弧と共有弧が存在すること、二分類が排他的であること、行政区域データが実在すること、色比、ポリゴンstroke禁止、公開側ファイル未変更を検査します。専用ActionsはChromiumとWebKitで9地域を表示し、ズーム/ドラッグ同期と各地図の同寸法を確認して、比較スクリーンショットをArtifactへ保存します。実機での島のつぶれ・低視力/色覚差の表示評価は、正式採用前に必要です。

## 変更影響

このDraft PRは `v2/verification/coastline-accessibility/` と専用GitHub Actionsだけを追加します。正式版、共有クイズCSS/JS、行政区域データ、Topology、県色、選択点滅、ラベル、吹き出しには変更ありません。PR #290までのR02条項に本試作が矛盾する点はないと判断します。規則集のR02現行コード記載は全国図の共通/個別経路の違いも含み、今回の色・線方式変更による規則改訂は行いません。

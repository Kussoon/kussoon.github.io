# 市区町村境界線の比較試作

公開版の海岸線改善（候補A）を保ち、市区町村の内部共有境界線の描画だけを比較する独立ページです。

## 比較する表示

- 現行：海岸線 `#486574` / 2.4px、内部境界 白 / 1.2px
- 候補：海岸線は現行と同一、内部境界 `#657b84` / 1.1px
- 両案で同一の2026年版Topology、塗り色、対象地域、画面縮尺を使用。地図移動と拡大縮小も同期します。
- ポリゴンstrokeは使わず、区域間共有Topologyアークを一つの境界pathで描画します。規則集R02を維持します。

## コントラスト比

候補線 `#657b84` は、海 `#d8ebf7` 3.63:1、陸地 `#f2f0dd` 3.87:1、範囲外 `#d5dee2` 3.26:1。現行の白線と陸地の組合せは1.15:1です。WCAG 2.2 SC 1.4.11の3:1を重要な図形の目標値として扱います。候補線の数値が基準に届いても、スマートフォン上で細かな境界が見えるか、線が過密にならないかは画像確認が必要です。

## 範囲と回帰確認

この試作は `v2/verification/municipality-boundaries/` と専用Actionsだけを追加します。公開地図、クイズ、色・点滅、形状データ、ラベル、吹き出し、操作には変更を加えません。

Chromium/WebKitの390×844表示で、宮古諸島・沖縄全域・奄美・五島・広島と香川の瀬戸内海・東京湾・西宮・北海道を比較し、共有境界と外周線の一重描画、色差、同一形状、ズームとドラッグの同期を検査します。実機Safariでの最終確認は別途必要です。

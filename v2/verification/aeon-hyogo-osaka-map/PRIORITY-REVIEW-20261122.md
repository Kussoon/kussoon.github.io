# 中もず店・四條畷の店舗位置を再照合

2026年11月22日。前回の追加照合後に残っていた優先2店を確認した。

## ダイエーグルメシティ中もず店

コーナン公式が案内するグルメシティ側（建物西側）と航空写真を照合。マピオンの店名・住所付き地点を店舗側の代表点として採用。同名OSM点は約20m西。 旧採用点から約47m。売場側の代表点、P3継続。

旧座標 34.553956, 135.511104 → 採用座標 34.55356796, 135.51091101。

## イオンスタイル四條畷

モール公式フロア図の1階食品売場を、駐車場案内の方位と航空写真に照合。北東側の売場範囲と対応するOSMの店名付き代表点を採用。 旧採用点から約147m。売場側の代表点、P3継続。

旧座標 34.746141, 135.629462 → 採用座標 34.7471063, 135.6305651。

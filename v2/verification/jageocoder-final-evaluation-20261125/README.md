# Jageocoder再変換結果の統合・最終評価

PR #762の全国採用案から、**113住所の座標対応範囲を詳細化**する。PR #764の207候補のうち110住所を採用し、再変換から重複を除いて3住所を追加した。残る確認対象は**1,387住所**。この採用案は受け渡し用で、Excel正本・公開地図への反映前の状態である。 [PR #762](https://github.com/Kussoon/kussoon.github.io/pull/762) · [PR #764](https://github.com/Kussoon/kussoon.github.io/pull/764)

## 審査基準と最終座標案

PR #762の採用案を基準にし、追加候補は対応階層が上がり、N03の期待区域内で異住所との完全同一点共有がない場合を審査対象にした。元と照会後の辞書住所、実際に消費した文字列、未照合部分から、番地・号、親番・街区、町字等を分類した。再変換で辞書レベル・座標対応範囲のどちらかが低下した表記と、数字の境界が変わる表記を除いた。区域内の同等以上のJageocoder候補が10m超離れる場合や、有効な同等以上のCSIS候補が100m超離れる場合は保留した。親番から番地・号への1km以上の移動も保留条件とした。

PR #764の207候補のうち97住所は、100m超移動し、正規化比較でも入力の照合部分と辞書階層が一致しないため維持した。例えば「神畑仲西460-1」の候補は「神畑460番地」で、字に相当する「仲西」と枝番1を辞書階層で確認できず、従来案と約495m離れている。採用113住所のうち28住所は同一点で対応階層の根拠だけが変わり、85住所で座標が変わる。1km超移動する48住所は、照合した町字・番号と辞書階層の整合を条件にした。枝番等が残る点の位置付けは親番点である。現地の施設や入口は住所だけでは特定できない。

| 最終座標対応範囲 | PR #762 | 最終案 | 残る確認対象 |
|---|---:|---:|---:|
| 番地・号まで | 3,348 | 3,390 | 164 |
| 親番・街区等まで | 947 | 995 | 995 |
| 町字・丁目等まで | 314 | 224 | 224 |
| 施設根拠あり（前回資料から継承） | 4 | 4 | 4 |
| 合計 | 4,613 | 4,613 | 1,387 |

出典別はABR系3,368、CSIS 1,093、Jageocoder元入力110・再変換3、その他の従来出典39。行政区域は期待区域内4,595、区域外100m以内18、100m超0。国土交通省「国土数値情報（行政区域データ、N03、2026年1月1日時点）」を加工し、PR #761の期待自治体コードを使用。座標のHaversine距離は点間の差を示し、現地誤差の計測値ではない。 [PR #761](https://github.com/Kussoon/kussoon.github.io/pull/761) · [N03](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html)

異住所共有は、現行・CSIS・PR #762・Jageocoder元入力と再変換の候補全体で69地点・152住所。最終採用案だけに絞ると3地点・6住所が相互共有し、他方式や他候補との共有まで含めれば15住所。共有は、明確な後続付記を除き、空白・文字幅・番号区切りを整理した比較住所と経緯度の数値完全一致で判断した。

## 有効だった正規化と逆効果

各方法の表記単位。複数の方法を試した住所があるため、方法別の改善数は住所単位の64とは母数が異なる。

| 方法 | 表記数 | 辞書レベル改善 | 対応範囲改善 | 最終採用 |
|---|---:|---:|---:|---:|
| 枝番・号の区切り | 120 | 34 | 53 | 2 |
| 空白除去 | 116 | 32 | 34 | 1 |
| 数字・ハイフン半角化と空白除去 | 836 | 11 | 13 | 0 |
| 日付注記の除去を含む表記整理 | 13 | 12 | 12 | 0 |
| 街区を番にする表記 | 5 | 1 | 1 | 0 |
| 同じ数列の台帳公式原文 | 4 | 0 | 0 | 0 |
| 塩釜市を塩竈市に表記補正 | 1 | 1 | 1 | 0 |

辞書レベル・対応範囲のいずれかが下がった7表記は不採用。例えば、`2-5-6 1号室` の空白を除くと `2-5-61号室` となり、住所番号の境界が崩れる。公式原文への差し替えでも、`葛飾区葛飾区` や `港北区港北区` の行政区重複で精度が低下した。街区を「番」に置き換えた5件には、対応範囲が低下する例も1件あった。日付注記除去と半角化の試験には空白除去も含む場合があり、改善を個々の変更の単独効果には帰属させていない。塩竈市の正字への変更でJageocoderの照合は改善したが、最終案ではPR #762を維持した。

## 残る確認事項

最終案の未解決は1,387住所。PR #762の1,410住所のうち42住所は番地・号まで採用できたため確認対象から外し、継続1,368住所に追加19住所を加えた。PR #764の1,326住所は207候補を前提とした暫定集計であり、今回は辞書階層との照合条件を追加した。

| 原因・確認事項（重複あり） | 件数 |
|---|---:|
| 番号・枝番・号の位置未確定 | 995 |
| 元入力で末端ノード座標なし | 646 |
| 町字・行政代表点まで | 224 |
| 照合語と辞書階層の表記差があり100m超 | 102 |
| 元JageocoderとPR #762が同粒度で100m超 | 24 |
| 採用案が区域外100m以内 | 18 |
| 採用案に方式横断の異住所同一点共有 | 15 |
| 採用案と再変換が同粒度で100m超 | 4 |
| 詳細化候補に異住所共有があり保留 | 2 |

一括の追加再変換は提案しない。再照会を追加する条件は、別表記の同一性を自治体の住所・地番資料で確認できる場合や、住所番号と号室等の境界を原資料から確定できる場合とする。末端ノードに座標がない行は、表記変更で座標が付くという実測根拠が得られるまでは、他の住所データに実座標の根拠を求める。

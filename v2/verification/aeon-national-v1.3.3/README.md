## PR #762から1km超移動する48住所

統合前に全48件の採用ノードを元の全国変換または再変換のJSONLへ戻し、照合文字列、辞書住所階層、未照合部分、採用座標、期待区域コードを再照合した。全件で照合部分と辞書階層の正規化一致、期待区域内、同一点の異住所共有なしを確認。PR #762で採っていた町字・丁目の代表点から親番・街区等まで詳細化した。枝番等は未照合のまま保持し、店舗の建物や入口を確定していない。各IDの距離・根拠は `pr762-over-1km-review.csv` とExcelの同名対応シートを参照。 [PR #762](https://github.com/Kussoon/kussoon.github.io/pull/762) · [PR #765](https://github.com/Kussoon/kussoon.github.io/pull/765)

## Excelと地図の検証

- Excelを保存後に再読込し、全国統合・通常掲載・地図表示用シートとJSON、PR #765の座標とIDを全4,613件突合した。緯度経度の逆転、無効値、欠落、重複IDは0件。48件の個別検証と同じN03ポリゴンで全国の区域結果を再現した。
- Ver.1.3.2の既往欄「緯度・経度」「座標精度区分」「座標確認日」等は保持した。現在の地図は「採用緯度・採用経度」「採用座標対応範囲」を使用する。旧採用座標や出典は「Ver1.3.2採用座標の保存」に追加保存し、既存の履歴・参考資料等49シートは全セルの値を比較して一致を確認した。坂田店のユーザー提供点も維持した。
- 採用候補の取得日時は記録を継承した。個別取得時刻を持たないJageocoder出力には調査日とその根拠を記録した。座標の採用案の日付は調査基準日の2026年11月25日。個別の未照合部分は元応答または明記した比較用表記で保持した。
- Ver.0.10のLeaflet、屋号の配色・凡例、店名・住所検索、都道府県・屋号絞り込み、店舗一覧、白い数字付きマーカーを継承した。座標の対応範囲をフィルターと店舗詳細に追加した。町字・丁目等では実際の店舗位置と異なる場合がある旨を表示する。
- ChromiumのPC幅1440pxとスマートフォン幅390pxで、読み込み、検索、複合条件、全精度区分の件数、解除、店舗詳細、代表点の注記、白い共有マーカー、ズーム、全体表示、地理院タイル応答を確認した。PCでは一覧のページ切替も確認した。スマートフォンはタッチ対応のブラウザエミュレーションで確認した。

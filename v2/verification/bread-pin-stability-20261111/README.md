# 阪神間 パン屋マップ｜ピン表示の安定性修正（検証用）

調査・作成日：2026-11-11。対象：最新mainの `maps/unified-bread-map.html`（HTML Version 1.3.11、blob `e2278afe8a3a0435f7cbfe3eb15c02c36ee8236b`）。

## 確認した問題

1. MarkerClusterの外部スクリプト読込失敗時に、存在しない `.mapnote` へ `append` しようとするコードがあり、JavaScript例外になる。HTMLに `.mapnote` 要素が存在しないことをソースで確認した。
2. PR #414の短時間の連続検索試験で、No.17→97→107→111の最後のNo.111のみピンDOMが30秒現れないことが記録された。リストと詳細は切り替わり、pageerrorは空。発生原因は未特定。従来のMarkerCluster 1.5.3のズーム・移動処理との相互作用は仮説である。

## 今回の限定修正

- 検索・絞込後に**地理的に1地点だけが表示対象**の場合、MarkerClusterを経由させず通常のLeafletレイヤーへ追加する。施設重複ピンの既存動作は維持する。
- MarkerClusterのクラスタ展開・収束アニメーションを無効化し、連続した `clearLayers / addLayer / setView` での遷移依存を小さくする。
- MarkerClusterを読み込めない場合は `L.layerGroup` で地点を個別表示し、存在しなかった `.mapnote` を生成して警告を表示する。

店舗データ、座標、掲載区分、店名、住所、リンク、公開文、フッター、Umami、通常の地図表示ロジックは変更しない。

## 自動テスト

`v2/tests/bread-pin-stability.browser.cjs` により、Chromium/WebKit × 1440px/390pxで、
- 公開対象・通常・参考・閉店件数
- No.17→97→107→111を含む連続検索と逆戻り、および全件表示からNo.111への切替
- 検索結果の詳細・ピンDOMの表示と元データ座標の一致
- MarkerClusterスクリプト通信失敗時の画面継続と警告

を検査する。外部地図タイル・外部解析通信は遮断し、本番MarkerCluster 1.5.3を取得・SHA256確認して試験時だけ供給する。

**留保**：実際のiPhone Safari、オンラインの背景地図、低速ネットワーク、実地のピン位置は未確認。テストの成功は原因の完全な特定やあらゆる検索速度での不再発を証明しない。PR #414の診断結果との比較および実機テストが必要。

# 阪神間お菓子マップ｜クラスタ表示なし検証版

## 基準

- 公開ページ：`maps/unified-sweets-map.html` Version 1.0.9
- 基準データ：2026年11月13日版、店舗データ429件
- 検証ページ：同じHTML・同じ店舗データを基に、地図のマーカー表示だけを変更

## 変更内容

- Leaflet.markerclusterのCSS・JavaScript読込みとクラスタレイヤーを外しました。
- 表示条件に合う店舗ごとにマーカーを1つ作成し、拡大前から地図に追加します。
- 同じ地点に複数店舗がある場合も店舗ごとのマーカーを重ねて表示します。重なった場所を選ぶと、その地点の店舗一覧を開きます。
- すべてのマーカーを同じ大きさの丸にそろえ、白い中心点を付けました。通常掲載は緑、参考候補は赤で表示し、重なりを見分けやすくするため影を少し強めました。
- タイトル下に店舗情報の確認基準日（2026年11月1日）を表示します。個別の最終営業確認日は店舗詳細にあり、日付が未記録の店舗もあります。
- 店舗データ、検索、分類・市の絞り込み、詳細表示、地図操作は基準HTMLのままです。
- ページには`noindex,nofollow,noarchive`を設定しました。

初期状態では、既存の掲載条件により429件中379件が表示対象です。検索や絞り込みを行うと、条件に合う店舗のマーカーだけを表示します。

## 確認

- HTML内の429件の店舗データは基準HTMLと完全一致。
- 現行の掲載条件を適用した379件すべてについて、個別マーカーを追加するコードを確認。
- マーカーの重なる24地点は個別マーカーを維持し、選択時の店舗一覧を残しています。
- 凡例を緑の丸と赤い丸に合わせました。
- MarkerClusterのCSS・JavaScript・生成処理がないことを確認。
- インラインJavaScriptの構文確認に合格。

この実行環境ではChromiumを起動できなかったため、ブラウザー上の見た目とタップ操作は未確認です。公開版は変更していません。

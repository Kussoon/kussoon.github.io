# 全国イオン系列スーパー 座標改善の採用案

基準日 2026年11月23日。照合日 2026年11月25日。Ver.1.3.2の通常掲載4,613店舗。

## 結果

全国の採用案4,613店舗のうち、CSIS座標または照合範囲の変更候補は **1100店**。前回の1,136候補と住所修正による再照会の結果を全国統合ID単位で比較しました。優先246店のうち採用案を変更したのは **164店**。

CSIS照合住所が公式原文の住所番号まで達していない部分一致のうち、Ver.1.3.2の基準日・正規化・ジオコーディング用住所が原文と異なるもの、および行政区域の疑義で再処理が必要なものを対象としました。入力単位は **621店・770件**。同じ入力は店舗内で重複送信せず、異なる候補表記がある場合は最大2種を比較しました。今回の再照会結果から **12店**を採用案に選びました。前回の有効な全件応答は比較根拠に使用しました。公式住所原文は成果物にもそのまま収録しています。

## 審査方法

住所番号までの照合を優先しました。照合粒度の向上、期待行政区内、異なる住所との座標非共有を確認したものを採用候補とし、同粒度の候補が離れて競合する場合は保留しました。現行点が町字の代表点なら、より細かな点と距離が離れる場合があります。親番を採った行では枝番・号の未照合を区別します。施設の実位置はこの分類から推定していません。

優先246店は、引継ぎの公式店舗資料URL、基準日住所、前回照合の番号・行政区域・位置差と今回の再照会結果を突合しました。境界付近、番号相違、同精度や独立根拠のない大幅乖離を未解決として引き継ぎました。優先対象全店について施設資料を新規に個別取得した範囲はありません。全国の異なる住所の座標共有は、前回からの **129店舗**を個別の表に記録しました。現行点を維持した場合の共有は未解決表にも残しました。

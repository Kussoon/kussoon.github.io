## 今後の更新ルール

1. このREADMEを固定の入口とし、現在の管理用マスターを示します。iPhoneへ毎版保存する必要はありません。
2. 新版Excelを`masters/`に版番号・日付付きの別名で追加します。過去版を削除したり、候補版を勝手に正式版へ変更したりしません。
3. `manifest.json`の現在版、採用状態、データ基準日、SHA256、シート名、件数を更新します。最新版という名前の重複コピーは作りません。
4. 比較用CSVを`views/`に追加します。CSVはGitHubで差分を見るための補助資料です。Excelの数式・他シート・履歴を含まないため、正本の代わりにはしません。
5. 根拠・旧値・新値・採否は監査フォルダとPRに残します。採用が確定した変更だけを次のマスター候補へ適用します。
6. ドラフトPRでファイル保全と整合性、公開HTMLとの差異を確認します。正式反映・マージ・公開はユーザーの別途承認後に行います。

マスターExcel、監査Excel、公開HTMLを区別します。GitHub Actionsのスクリーンショット等には保存期限がありますが、コミットされたExcelはその期限とは無関係です。過去版は`masters/`とGitHub履歴から取得できます。

## 読み取り回数の想定

| 操作 | 教材同期 | 履歴同期 |
| --- | --- | --- |
| 同じ端末の通常ログイン | epoch確認＋変更教材の差分（キャッシュが無効/24時間経過なら教材全件） | epoch確認＋変更セッションの差分。履歴詳細は直近3件/言語の未キャッシュ分 |
| 新規登録後 | 登録前に差分同期、登録後の差分同期 | 影響なし |
| 問題編集・学習判定 | 次回の差分同期で変更問題を取得 | 完了セッションの新規文書を差分取得 |
| 管理JSONの一括更新 | 更新前の完全照合で教材全件を一度取得。書込み後の端末更新は変更分のみ差分取得 | 影響なし |
| 教材置換・永久削除 | epoch変更で他端末が全件再同期 | 置換が履歴を削除する場合epoch変更で全件再同期 |
| 履歴初期化 | 学習値更新分を差分取得 | historyEpoch変更で全件再同期 |
| 翌日 | 24時間経過後の初回同期で全件取得 | 24時間経過後の初回同期で全件取得 |
| 復習途中から再開 | キャッシュ同期の後、active文書と必要なチャンクを取得 | セッション要約は差分/キャッシュ |

Firebase Emulatorの読み取りメーターを使った数値計測は未実施。差分取得は更新対象件数に比例し、初回・24時間全件同期は教材数/履歴数に比例する。

## データ・同期契約

- 教材は `users/{uid}/expressions/{id}`、履歴要約は `users/{uid}/sessions/{sessionId}`、チャンクは `users/{uid}/reviewChunks/{sessionId}-{index}` に保存する。
- IndexedDB内のキーはFirebase UIDごとに分離する。教材と履歴要約は別キーで保存する。
- 教材差分は `syncUpdatedAt >= cursor` で取得する。登録、編集、採点、置換、管理JSON反映は同期フィールドを更新する。
- 学習中でない表示タブは5分間隔で差分確認し、タブ再表示時と学習・登録開始前にも同期する。変更がない定期確認はバッチ名2件とepoch確認2件を読み、変更教材文書だけを追加で読む。
- `review/bankEpoch` が変わった場合、または24時間経過時は教材全件を再取得する。教材の物理削除を差分結果だけで表現できないため、削除・置換はepochで無効化する。
- 履歴差分も `syncUpdatedAt >= cursor` で取得する。新しいセッション完了時に同期時刻を記録する。`review/historyEpoch` が変わった場合、または24時間経過時は履歴要約を全件再取得する。
- 通常ログインの履歴要約取得は、全件でなく更新分のみ。初回端末・24時間再同期・履歴epoch変更時は全件読み取りが発生する。履歴詳細チャンクは直近3セッション/言語だけを読み、キャッシュした直近回答は再利用する。
- 登録前編集の下書きは端末内localStorageに保存する。Firestoreには登録確定時のみ書き込む。登録操作は行ごとの安定ID、重複照合参照、言語別採番カウンターをtransactionで扱う。
- 各利用者の実データはFirebase UID配下で分離し、本番データの試験書き込みを行わない。

## 復習範囲・UI

- 既定の復習範囲は「すべての問題（既定）」。
- 「出題から外した問題のみ」「出題から外した問題も含めたすべて」「ひとまず覚えた問題」は選択肢として表示しない。
- 「一つ前の問題」は参照専用で、履歴・進捗を更新しない。
- 「この問題は飛ばす」は「ここで終了」の左側。編集ボタンは右寄せ。
- 「スピード・回転数重視！」バナーは学習履歴の下に固定配置し、1.5秒表示・0.5秒非表示を維持する。
- 模範解答以外の表現に関する指定定型文は表示しない。

## 制限と注意

- GitHub PagesのプレビューURLは公開URLであり、noindexはアクセス制限ではない。
- プレビューでログインすると本番Firebaseの実データを読み取る。試用モードの採点は保存しないが、通常学習・登録・編集・削除は本番Firebaseに反映される。
- Firebase実環境の読取回数、複数端末競合、権限ルールは、合成データを用いたエミュレーター検証が完了するまで「未確認」として扱う。

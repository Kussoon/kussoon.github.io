# Authentication setup (not deployed)
Use a dedicated hostname such as review.kussoon.com with Cloudflare Access in front of both the app and API. Configure Google as the identity provider and an explicit email allowlist. Set TEAM_DOMAIN and POLICY_AUD on Worker and ALLOWED_EMAILS as a secret (comma-separated). Disable unneeded workers.dev and preview routes. JWT is verified against the configured issuer, application audience, expiry and signature; API account identity derives from verified subject only. No cross-origin API access. Future mutation routes must enforce same-origin requests. Do not publish user emails, Google secrets or content in GitHub. Test unauthorized, expired, wrong-audience and cross-account access before real data import.

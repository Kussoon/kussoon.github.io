# 語学復習アプリ 変更履歴

## v1.6（2026-11-28）検証版
- v1.5のIndexedDB教材キャッシュ、差分同期、24時間全件同期、履歴カレンダー、永久削除、かたまり名同期、復習再開などを維持。
- PR #774の登録前編集、端末別下書き、個別/一括削除、重複候補処理、安定ID再試行を統合。
- 登録前重複判定を教材全件取得から差分同期後のキャッシュへ変更。
- 履歴要約をUID別IndexedDBキャッシュ＋差分取得に変更。履歴の削除・置換はhistoryEpochで無効化し、24時間で全件再同期。
- 表示中の教材差分確認を毎分から5分間隔に変更し、表示再開時・学習/登録開始前の同期を維持。
- 正式版 `index.html` は未変更。検証版は承認後に別途反映する。

## v1.5
- IndexedDBによる教材キャッシュ、差分同期、24時間ごとの全件同期。
- 厳格な未学習判定、復習再開、履歴カレンダー、永久削除、かたまり名端末間同期。
- 長い復習の分割チャンクと履歴表示を追加。

## v1.2 / PR #774

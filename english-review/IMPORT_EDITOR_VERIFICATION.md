## 登録と再試行

登録前の「重複候補」は、同じ言語で外国語が一致する行に付きます。登録時の自動省略は日本語と外国語の両方を正規化して照合します。「別の問題としてすべて残す」を選んでも、通信切断で再試行する際は同じ下書き行の固有IDを再利用します。

下書きは端末のブラウザー内に、利用者と言語ごとに保存します。登録済みの表現は Firestore に保存します。登録処理は表現・言語別カウンター・重複照合用の参照を同一トランザクションで書き込みます。既存教材の初回番号が未確定の場合は、その理由を表示して中断します。複数端末の同時登録の試験では、両方の端末で今回の登録機能を使用しました。

## iPhoneで確認する手順

1. 登録機能は正式ページの「復習表現を登録」から開きます。練習用のデータで操作する場合は、合成サンプルを使える[検証ページ](https://kussoon.com/v2/english-review-import-preview/)を開きます。
2. 言語を選び、タブ区切りの表現を貼り付けて「登録前に編集する」を押します。個別欄を編集し、再読み込みして同じ言語を開くと内容を確認できます。
3. 実際に追加する表現を確認し、「編集済みの表現を登録する」を押します。通常の重複はまとめて省略されます。

## 再実行

`tests/import-editor-model.cjs` は jsdom、`tests/import-editor-browser.cjs` は Playwright と @sparticuz/chromium を使用します。ブラウザー試験は合成の認証・保存処理を使い、外部リクエストを遮断します。

Firestore 試験は Firebase SDK 13.4.0、@firebase/rules-unit-testing、jsdom、Java 21、firebase-tools を使用します。対象はローカルの `demo-review774`、Firestore のポートは8087です。既定では FAMILY_ACCESS_SETUP.md のルールを使い、`REVIEW_FIRESTORE_RULES` でテスト用ルールファイルを指定できます。

```sh
node english-review/tests/import-editor-model.cjs
node english-review/tests/import-editor-browser.cjs
firebase emulators:exec --only firestore --project demo-review774 --config /path/to/test/firebase.json 'node english-review/tests/import-editor-firestore.cjs'
```

既に導入した依存モジュールは `REVIEW_JSDOM`、`REVIEW_CHROMIUM`、`REVIEW_RULES_TESTING`、`REVIEW_FIRESTORE` で指定できます。
